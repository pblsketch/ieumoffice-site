AI 連線說明

連結 AI

IeumOffice 的 AI 透過你現在使用的 Claude 或 ChatGPT 訂閱運作。沒有訂閱的話，連結免費 AI 就可以。在下方選擇適合你的方式，滑鼠游標會實際移動，告訴你該按哪裡。

你現在在用哪種 AI？

我有 Claude 付費訂閱 Pro 或 Max 方案 我在用 ChatGPT 不必安裝程式，登入就能連結 兩者都還沒有 大約一分鐘連結免費 AI 連結時卡住了 停在登入、版本過舊等

連線畫面有三個地方：第一次執行時引導中的 AI 連線步驟、還沒連結任何 AI 的 AI 面板，以及首頁左下角的設定 → AI。從哪裡開始，步驟都一樣。

Claude 訂閱

用 Claude 訂閱連結

需要 Claude Pro 或 Max 方案。免費的 Claude 帳戶無法連線。IeumOffice 透過安裝在電腦上的 Claude Code 程式取得回答，所以第一次要先安裝這個程式並登入。不需要 API 金鑰。

卡住時

連結時卡住了

找到卡片上顯示的文字，展開來看。

停在「正在登入…」

如果瀏覽器已經開啟登入畫面，在那裡登入並按允許就可以。花點時間也沒關係。這時請不要按卡片下方的連結或開啟登入視窗按鈕。按下去會停止目前的登入，從頭重新開始。

如果瀏覽器完全沒有開啟，請這樣做。

  1. 按卡片下方的連結，或 25 秒後出現的開啟登入視窗按鈕。會開啟一個黑色視窗。這時如果瀏覽器開啟了，就在那裡登入並按允許。視窗會自動關閉並完成連線。
  2. 如果瀏覽器還是沒有開啟，用滑鼠拖曳選取黑色視窗中以 https:// 開頭的網址，按滑鼠右鍵複製。貼到瀏覽器的網址列，就會開啟登入畫面。
  3. 登入並按允許後，瀏覽器會顯示一組代碼。複製完整的代碼。有複製按鈕的話就按它。
  4. 在黑色視窗內按一下滑鼠右鍵貼上，然後按 Enter。貼上的代碼沒有顯示在視窗中也是正常的。
  5. 視窗關閉、卡片變成「已連線」就完成了。

視窗中出現 Invalid code 的話，表示代碼沒有複製完整。代碼中間有一個 #，前後兩段都要包含在內。請不要關閉視窗，重新複製代碼後貼到同一個視窗。

要從頭再來，請按卡片上的取消登入，再按一次登入。

ChatGPT 卡片（直接連結）沒有黑色登入視窗。請在瀏覽器中登入，一直做到允許為止。瀏覽器沒有開啟，或想重新來過，請按取消登入後再按一次使用 ChatGPT 繼續。

出現「登入沒有完成」

瀏覽器沒有完成登入，只顯示一組代碼就停住時，會出現這個提示。那組代碼要貼到登入視窗，而不是應用程式中。已經顯示過的代碼不能再用，請從頭重新登入。

  1. 按卡片上的開啟登入視窗按鈕，會開啟黑色的登入視窗。如果想改用瀏覽器重試，請按改在瀏覽器中登入。
  2. 照上方停在「正在登入…」的第 2～5 步在瀏覽器中登入，再把顯示的代碼貼到那個視窗。

還沒登入的卡片上也有瀏覽器顯示了代碼？連結，可以一開始就用這個視窗登入。這個登入視窗只能在 Windows 上使用（IeumOffice 0.12.7 起）。

如果 ChatGPT 卡片顯示「登入沒有完成」，表示你沒有允許這個應用程式使用 ChatGPT 方案，或沒有在 10 分鐘內完成登入。不需要登入視窗，再按一次使用 ChatGPT 繼續就會從頭開始。

出現「程式版本過舊」

電腦上的 Claude Code 或 Codex 是舊版本。按卡片上的更新，會在新視窗中執行該公司的官方更新。在視窗中更新完成後，請回到 IeumOffice。應用程式會自動重新檢查。

如果卡片上同時顯示「此應用程式執行的檔案」，就必須更新那個檔案。更新安裝在 WSL（Ubuntu）或其他資料夾中的副本，不會變更這個檔案。沒有更新按鈕的話，請在 Windows PowerShell 中執行卡片上寫的指令。

顯示「已登入，但不是訂閱方式」

程式登入的不是訂閱帳戶，而是 API 金鑰或依用量付費的帳戶。這時按仍要使用，每次請求都會向那個帳戶收費。在你按下之前，IeumOffice 不會使用那個連線。

想用訂閱的話，在設定 → AI 的卡片上按使用其他帳戶登入，用你訂閱中的帳戶重新登入，再按重新檢查。

出現「無法檢查連線狀態」

程式沒有及時回應，或檢查時發生了問題。請稍後按重新檢查。如果電腦像公司或學校那樣透過 Proxy 連上網路，請先在 PowerShell 中確認 claude 或 codex 能不能用。在那裡不能用的話，在 IeumOffice 中也不能用。

我只有免費的 Claude 帳戶

Claude 要 Pro 或 Max 方案才能連結。用免費帳戶登入無法連線。如果不打算訂閱，請連結免費 AI。按卡片上的選擇其他方式，就會回到一開始的問題。

在 Mac 上連結時 測試版

在 Mac 上，卡片顯示的不是安裝按鈕，而是官方安裝說明。按下後會開啟該公司的安裝說明，請照上面寫的在終端機中安裝 Claude Code 或 Codex。安裝後回到 IeumOffice，卡片會變成「尚未登入」，之後的步驟和 Windows 一樣：按登入，在瀏覽器中登入即可。

如果顯示版本過舊，請在終端機執行卡片上寫的更新指令。

直接連結 ChatGPT 時不需要安裝任何程式，所以在 Mac 上的步驟也和 Windows 相同。

還是不行的話，請按連線畫面下方的複製求助資訊，再貼到傳送意見回饋送出。只會複製連線狀態和程式版本，不包含帳戶和檔案路徑。

IeumOffice 不會讀取或儲存 Claude Code 或 Codex 的登入資訊。登入只在該公司的程式和網頁上進行， IeumOffice 也看不到你的 ChatGPT 密碼。直接連結 ChatGPT 時，只會在這台電腦上保留 OpenAI 發給本應用程式的那一組登入（在 Windows 上會加密保存），中斷連線時會先向 OpenAI 要求結束連線，再刪除。訂閱額度用完時，只會停止請求並告訴你，不會自動改用需要付費的連線。
