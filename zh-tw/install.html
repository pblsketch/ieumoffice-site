Windows 11

出現「智慧型應用程式控制已封鎖」

這是新買的筆電或剛重灌 Windows 的電腦常會跳出的視窗。IeumOffice 是免費發行的程式，沒有能讓 Windows 確認發行者的簽章，所以不只安裝時，執行時 Windows 11 也會擋下。這個視窗沒有執行按鈕，也沒有只允許這個程式的方法。關閉智慧型應用程式控制後，就能安裝和執行。不過再次開啟的話，IeumOffice 又會被擋下，所以使用 IeumOffice 期間必須維持關閉。

  1. 跳出封鎖視窗時，按確定關閉。
  2. 在開始按鈕旁的搜尋輸入 Windows 安全性並開啟，再按左側的應用程式與瀏覽器控制。
  3. 按智慧型應用程式控制設定。
  4. 選擇關閉。現在再次開啟下載的安裝檔，就會開始安裝。

智慧型應用程式控制是擋下從網路下載的陌生程式的功能。關閉後這項保護會減少，但就能使用 IeumOffice；Windows 安全性的病毒與威脅防護（Defender）仍維持開啟，會繼續掃描病毒。之後再次開啟的話，IeumOffice 就無法執行。

關閉後如果接著跳出藍色的「Windows 已保護您的電腦」視窗，在那個視窗按其他資訊 → 仍要執行即可。做法請見出現「Windows 已保護您的電腦」。

按從 Microsoft Store 取得應用程式也找不到 IeumOffice，因為它沒有上架到 Store。有些電腦會提示「關閉後就無法再改回來」，關閉前請先讀一下。改了設定之後還是被擋下，請重新啟動一次電腦。如果是公司或學校配發的電腦，可能無法變更這項設定，請告知管理電腦的人。畫面是為了說明而重繪的，依 Windows 版本不同可能略有差異。

Mac · Linux

在 Mac 和 Linux 上安裝時

在 Mac 上第一次開啟時 測試版

適用於 macOS 12 以上。請在蘋果選單 →關於這台 Mac中確認晶片。以 Apple M 開頭的話，下載 Apple Silicon 版檔案；如果是 Intel，就下載 Intel 版檔案。這是沒有 Apple 開發者簽章的免費測試版，所以只有第一次需要你自己允許。

  1. 打開下載的 .dmg，把 IeumOffice 拖到應用程式資料夾。
  2. 在應用程式資料夾中打開 IeumOffice。跳出警告視窗時，按完成。
  3. 打開系統設定 → 隱私權與安全性，在下方「已阻擋『IeumOffice』」旁按強制打開，然後輸入 Mac 的密碼。
  4. 在再次跳出的視窗中按打開。之後就能直接打開。

如果顯示「已損毀，無法打開」，請不要丟到垃圾桶，在終端機執行下面這一行之後再打開。

xattr -dr com.apple.quarantine /Applications/IeumOffice.app

從 0.12.11 起，放在應用程式資料夾中的 App，只要在更新視窗中按立即更新 →立即重新啟動安裝，就會換成新版本並重新開啟。如果你用的是 0.12.10 以下的版本，這一次請在這裡下載 0.12.11 覆蓋安裝。直接從磁碟映像檔打開的 App，更新視窗會開啟下載頁面。App 沒有自行更新的話，在這裡重新下載覆蓋安裝即可。 Claude Code 或 Codex 請依照 AI 連線卡片上的「官方安裝說明」安裝（在 Mac 上連結 AI）。

在 Linux 上安裝時 測試版

提供三種 64 位元（x86_64）Linux 用的檔案。請選擇適合你所用發行版的檔案下載。

  • AppImage — 不必安裝，只要給予執行權限（chmod +x）就能直接開啟。會自行更新。
  • .deb 套件 — Ubuntu、Debian 系列：sudo apt install ./ieumoffice_*_amd64.deb
  • .rpm 套件 — Fedora、RHEL、openSUSE 系列：sudo dnf install ./ieumoffice-*.x86_64.rpm

.deb 和 .rpm 會安裝到 /opt/IeumOffice，並連結終端機指令 /usr/bin/ieumoffice。有新版本時，App 會通知你； AppImage 則能在 App 中直接更新。Claude Code 或 Codex 請依照 AI 連線卡片上的「官方安裝說明」安裝。
