說明

常見問題

整理了使用 IeumOffice 時常卡住的地方。內容以 0.12.12 為準。這裡沒有的問題，請透過傳送意見回饋告訴我們。

支援環境

手機、行動版、iPad、Android 上也能用嗎？

不能。IeumOffice 是安裝在電腦上的桌面程式。沒有手機、行動版、iPhone、Android、 iPad 或平板用的 App，也沒有用網頁瀏覽器開啟的版本。無法安裝成平板或手機 App。

作業系統支援
Windows 10、11（64 位元）正式版
macOS（Apple Silicon、Intel）測試版
Linux x64（AppImage、deb、rpm）測試版
iPad、iPhone、Android不支援

Mac（測試版）上也能用嗎？

可以。Mac 的 Apple Silicon 和 Intel 都以測試版發布。Apple Silicon 支援 M1 以後的機型， Intel 從 0.12.4 起支援。安裝檔在下載頁面選擇。

Intel Mac 從什麼時候開始支援？

Intel Mac 從 0.12.4 起，和 Apple Silicon 一起以測試版發布。可以在下載頁面選擇 Intel Mac 用的安裝檔。Mac 和 Linux 是測試版，有些部分開發者無法親自確認，要靠使用者的回報來確認。

Windows 7 或 32 位元 Windows 能用嗎？

不支援。只支援 64 位元的 Windows 10、11。32 位元 Windows 和 Windows 7 以前的版本無法安裝。

費用

真的免費嗎？費用怎麼算？

程式是免費的。編輯、儲存文件沒有付費限制，也不需要帳號或訂閱。 IeumOffice 不另外收取任何費用。

AI 功能透過你已經在用的 Claude、ChatGPT 訂閱，或你自己填入的 API 金鑰運作。訂閱費是付給那家公司的，不需要另外付錢給 IeumOffice。使用 API 金鑰（OpenRouter、Gemini）時，可能會依用量向那家公司付費，也有附免費額度的金鑰。

應用程式不會自動把你改成付費的 API 金鑰或依用量計費的連線。額度用完時，會停止請求並告訴你原因。

安裝

有不必安裝就能用的免安裝版嗎？

沒有。目前還沒有做不必安裝就能執行的免安裝版（壓縮檔），也沒有放在 USB 隨身碟中帶著走的版本。

Windows 用安裝檔（.exe）安裝一次後，從開始功能表或桌面執行。 Mac 打開 .dmg 後移到應用程式資料夾；Linux 則執行 AppImage，或用 .deb、.rpm 安裝。

安裝卡住時，請到安裝說明選擇你現在看到的畫面來確認。

安裝

要怎麼移除程式？

Windows 請在設定 → 應用程式 → 已安裝的應用程式中找到 IeumOffice，按解除安裝。 Mac 請在 Finder → 應用程式中把 IeumOffice 丟到垃圾桶。Linux 依安裝方式，使用 sudo apt remove ieumoffice、 sudo dnf remove ieumoffice，或刪除 AppImage 檔案。

移除到一半停住，或無法重新安裝時，請再安裝一次相同版本，然後重新嘗試移除。還是不行的話，請透過傳送意見回饋告訴我們停在哪個畫面。

設定和最近文件的紀錄可能會留在使用者資料資料夾中（Windows %APPDATA%\IeumOffice、Mac ~/Library/Application Support/IeumOffice、Linux ~/.config/IeumOffice）。要完全清除，請在移除後自行刪除這個資料夾。

安裝

第一次開啟時停在「沒有回應」或灰色畫面

這是在開啟了 Windows 安全性受控資料夾存取（勒索軟體防護）的電腦上會發生的問題。這項功能會阻止在「文件」資料夾中建立新資料夾，所以到 0.12.7 為止，這類電腦上的應用程式第一次開啟時可能會卡住。更新到 0.12.8 或重新安裝就能解決。

從 0.12.8 起，無法寫入「文件」資料夾時，會把新檔案儲存到使用者資料夾下的 IeumOffice 資料夾，並顯示一次「無法儲存到『文件』資料夾」的提示。如果想照原本那樣存到「文件」資料夾，請在 Windows 安全性的允許應用程式通過受控資料夾存取中加入 IeumOffice，然後重新啟動應用程式。也可以在設定 → 一般 → 預設儲存位置中選擇其他資料夾。

Hangul

Hangul 檔案存不了，出現「沒有儲存」

IeumOffice 儲存時，會先寫出新檔案，再把那個檔案讀回來，確認和畫面上的內容相同。讀回來的內容和畫面不同時，就不會覆寫原檔而是停下來。所以原檔會原封不動地保留。這不表示檔案壞了，而是為了避免用和畫面不同的結果毀掉原檔才停下來。這項檢查只在存成 .hwp 時進行。 .hwpx 是不同的格式，不做這項檢查。

  1. 在另存新檔中把檔案類型改成 HWPX，存成新檔案。儲存後請用 Hancom Hangul 開啟確認。
  2. 如果一定要存成 .hwp，請在另存新檔中選擇 HWP，存成新檔案試試看。可能會再次被同樣的檢查擋下。
  3. 還是不行，就用匯出為 PDF 保存目前畫面上的內容。
  4. 仍然不行的話，請透過傳送意見回饋把那份文件寄給我們。刪除或替換掉個人資料的副本也可以。

如果應用程式突然關閉，下次執行時會提議使用復原檔。復原檔會留在使用者資料資料夾的 hwp-autosave 中。

Markdown

在 Markdown 中按連結打不開

在 Markdown 編輯器中直接點選連結，游標會進入連結文字，方便你修改。要開啟連結，請按住 Ctrl 再點選（Mac 是按住 ⌘ 再點選）。像簡報畫面（F5）這樣唯讀的時候，直接點選就能開啟。

只有網址（http、https）和電子郵件地址（mailto）會用預設瀏覽器開啟。文件中的相對路徑、file:// 位址，以及原始碼檢視（Ctrl+E）中的連結，目前還無法開啟。

滑鼠移到連結上會出現手指游標，編輯時點一下卻打不開，是為了讓你能在原處修改連結文字。

PDF

可以把截圖貼到 PDF 上，或複製頁面嗎？

目前還沒有。在 PDF 編輯畫面用 Ctrl+V 貼上剪貼簿中截圖的功能，以及把頁面一次複製到剪貼簿的功能，都還沒有加入。

現在可以用以下兩種方法。

  • 用插入圖片，把存成圖片檔的截圖放進 PDF。
  • 用 PDF 工具 → 匯出圖片，把頁面存成 PNG 檔案。

貼上截圖和複製頁面，已經有人透過傳送意見回饋提出需求。如果你也需要，請透過傳送意見回饋告訴我們。

Excel

Excel 檔案相容到什麼程度？

日常的 .xlsx 工作都能做。支援儲存格編輯、公式、格式、表格、圖表（9 種類型）、樞紐分析表、設定格式化的條件、排序與篩選、資料驗證，以及工作表與活頁簿保護。 .csv 和 .tsv 也能以表格開啟，並以原本的格式儲存。

不過，並不是 Excel 的所有功能都完全一樣地支援。

  • 不會執行 VBA 巨集。開啟並儲存 .xlsm 檔案時，存放巨集的部分不會刪除，會原樣保留。
  • 外部資料連線、部分進階樞紐分析表、圖表和 OLE 物件，結果可能和 Excel 不同。
  • 儲存時會把結果讀回來確認，讀不出來就不會覆寫原檔。重要的文件，儲存後請用 Excel 開啟確認一次。

遇到不相容的功能，請透過傳送意見回饋連同檔案一起告訴我們。刪除或替換掉個人資料的副本也可以。

Excel

在 Excel 中要怎麼讓列高一致？

要讓儲存格高度（列高）一致，請選取多個列標題（1、2、3…），再從功能區選擇格式 → 列高…，輸入相同的數值。選取的列就會變成相同高度。想依內容調整成一致，請用格式 → 自動調整列高。

欄寬也是一樣，在格式 → 欄寬…中調整。也可以拖曳列標題的邊界來調整，或按兩下邊界自動調整。

AI 連線

可以用 ChatGPT 方案嗎？一定要有 Codex 程式嗎？

可以用，而且從 0.12.8 起不需要 Codex 程式。在連線引導中選擇我在用 ChatGPT，按使用 ChatGPT 繼續，瀏覽器就會開啟 ChatGPT 登入畫面。登入後允許這個應用程式使用你的方案，就完成連線。在設定 → AI 的 ChatGPT 卡片上也能做同樣的事。想看畫面示範，請見AI 連線說明。

如果這台電腦上已經在使用 Codex 程式，也可以透過 Codex 連結。代理程式模式和終端機指令跟以前一樣，需要 Claude Code 或 Codex 程式。

使用的 AI 設為自動時，會在已連結的 AI 中依 Claude、ChatGPT、Codex 的順序選擇。需要付費的 API 金鑰或依用量計費的登入不會被自動選擇。

AI

每份文件都要重新向 AI 說明同樣的背景嗎？

從 0.12.9 起，把它們歸成一個專案就可以了。在 AI 面板輸入框下方的專案中按新增專案，或用新增資料夾選擇你在用的資料夾。在首頁專案畫面寫好的指示，以及 AI 在對話中累積的記憶，會隨著在那個專案中的每次請求一起送出。AI 會在資料夾中找檔案來讀，同一個專案的對話在其他編輯器中也能接續。

指示、記憶和對話會存放在那個資料夾中的 .ieumoffice 資料夾裡。不想讓 AI 看到的檔案，可以在專案畫面的檔案中排除。沒有選擇專案時，就和以前一樣，每份文件各自對話。

檔案

可以開啟 Google 雲端硬碟中的檔案嗎？

從 0.12.9 起可以。在設定 → 整合中連結 Google 雲端硬碟後，按首頁的從 Google 雲端硬碟選擇，就會跳出 Google 的檔案選擇視窗。選好的檔案會以分頁開啟，儲存時會重新上傳到雲端硬碟。在 AI 面板中附加檔案時，也能選擇雲端硬碟中的檔案。

應用程式只會開啟你在選擇視窗中選的檔案和應用程式自己建立的檔案，不會查看整個雲端硬碟。把雲端硬碟的檔案交給 AI 之前，會先確認一次你目前使用的 AI 帳戶是否已關閉模型訓練。不會把雲端硬碟的檔案交給免費 AI 連線。

AI 連線

可以用 Gemini 付費方案連結嗎？

Gemini Advanced（Google One AI Premium）訂閱無法直接用在 IeumOffice 的 AI 連線上。在「免費使用」中連結的 Gemini，是在 Google AI Studio 建立的 API 金鑰。

填入付費的 Gemini API 金鑰，可能會依用量向 Google 付費，也有附免費額度的金鑰。應用程式不會自動把你改成付費的 API 金鑰。

如果你在用 Gemini Advanced 訂閱，目前需要連結 Claude 或 ChatGPT 訂閱，或在 Google AI Studio 建立 API 金鑰來連結。

授權

可以在公司、企業或機關中用於工作嗎？

可以。IeumOffice 是以 Apache License 2.0 發布的免費開源軟體。公司（企業）、學校、公家機關都能在不另外訂閱的情況下用於工作，文件編輯與儲存功能沒有付費限制。

AI 功能透過每位使用者的 Claude、ChatGPT 訂閱或自己填入的 API 金鑰運作。若要以公司帳號管理，請確認那家公司的條款。應用程式不傳送使用統計，文件留在電腦上。

授權全文在 GitHub 的 LICENSE 中。

Hangul

和 Hancom Hangul 有什麼不同？

IeumOffice 的 Hangul 編輯器能開啟並儲存 .hwp 和 .hwpx，可以做文字、表格、樣式、快速鍵等基本編輯。快速鍵大多比照 Hancom Hangul 2024，也能用 AI 修改文件或匯出成 PDF。

並不會完全重現 Hancom Office 的所有功能。追蹤修訂會以目前的內容開啟，追蹤紀錄不會被儲存。部分物件、欄位和頁面配置可能和 Hancom Hangul 不同。

重要的文件，在 IeumOffice 中儲存後，請用 Hancom Hangul 開啟確認一次。

AI 連線

可以用本機 LLM 嗎？

可以（0.12.6 起）。IeumOffice 不會自己執行模型，而是連到在你的電腦或公司內網執行的 AI 伺服器（例如 Ollama）。在設定 → AI 的本機 AI 中登錄伺服器位址，再用連線測試確認能不能對話。

只登錄不會改變正在使用的 AI，只會使用你自己選的伺服器。伺服器位址是電腦以外的網際網路位址時，會提醒你文件將送往那裡。沒有網路也能編輯和儲存文件。

AI

AI 說「重新送出正確的呼叫」

AI 用錯誤的格式送出修改文件的工具呼叫時，應用程式會請它重新送出那個請求。稍等一下，很多時候它就會重新回答。

如果同一個請求一直重複出現這種情形，請稍微改一下請求，或透過傳送意見回饋告訴我們是什麼樣的請求。一併附上畫面和對話紀錄，會比較容易找到原因。

更新

可以用電子郵件收到更新消息嗎？

沒有用電子郵件或簡訊寄送更新消息的服務。IeumOffice 不收集電子郵件地址。

應用程式每 4 小時檢查一次新版本。可以用分頁列的 ☰ 選單 → 檢查更新…（Mac 是說明 → 檢查更新…）立即檢查，有新版本時會在應用程式中通知你。不想自動檢查的話，請在設定 → 關於中關閉自動檢查更新。也可以從 GitHub Releases 頁面下載。

想在 GitHub 上收到新版本發布的通知，請在儲存庫選擇 Watch → Custom → Releases 即可。

這裡沒有的問題，請透過傳送意見回饋告訴我們。寫下卡在哪個畫面、想做什麼，能更快找到原因。
