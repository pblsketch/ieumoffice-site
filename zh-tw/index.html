從 Hangul 到 PDF， 一個視窗搞定。

Hangul（HWP）、Word、Excel、PowerPoint、PDF、EPUB、Markdown、HTML、心智圖、圖表檔案都能以分頁開啟編輯，並以原本的格式儲存。任何人都能免費使用。

測試版 · Windows 10、11（64 位元） · Mac（Apple Silicon · Intel） · Linux（x64 · deb、rpm）安裝說明

累計下載 Windows 安裝 Mac 安裝 Linux 安裝 GitHub 星星

Hangul

Hangul 檔案，
就存成 Hangul 檔案。

韓國的公文、申請表常以 Hangul（HWP）檔案往來，這些文件都能開啟編輯。改好後以原本的格式儲存，也能轉成 PDF 或直接列印。

以原本的格式儲存
.hwp 存成 .hwp，.hwpx 存成 .hwpx。第一次覆寫檔案時，會把原檔留成 .bak。另存新檔時，可以在兩種格式中選擇，或另存一份 PDF。
在 Hancom Hangul 中能再次開啟
開發時用數百份真實的 Hangul 文件確認過，修改後儲存的檔案能在 Hancom Hangul 2024 中開啟。
新文件與 PDF
可以在首頁新增空白的 Hangul 文件，寫好的文件能轉成 PDF 或直接列印。在 PDF 編輯器按「PDF 轉換」→「PDF 轉 HWP」，也能把 PDF 匯入成 Hangul 文件來編輯。
重複的工作交給 AI 面板
填表格儲存格、新增或刪除列與欄、填寫表單欄位、加入註腳和目錄，這類工作都可以請它代勞。

Hangul 編輯畫面以開源專案 rhwp 打造。

AI

只在需要時
交給 AI。

編輯器旁邊有 AI 面板。不用它，也不影響當作辦公軟體使用。想把填表格、修飾文句這類費工的事交出去時，開口請它，AI 就會用應用程式的編輯工具修改開啟中的文件。常交代的工作可以存成技能，在輸入框打 / 叫出來使用。

畫面中的對話是為了說明而舉的例子。

可以復原
AI 會列出改了哪些地方，不滿意就復原。
用資料做出新文件
讀取你選的檔案，做成簡報、HTML 網頁或心智圖。
向自己的文件發問
在首頁選好加了星號的檔案再發問，AI 會讀過那些檔案後回答。

個人資料

沒有伺服器，也沒有帳號。

IeumOffice 不傳送使用統計，文件在你的電腦上開啟和儲存。會離開電腦的，只有你請 AI 幫忙時傳給那家 AI 公司的內容。

查看完整隱私權政策
  • 不讀取、複製或儲存 Claude Code 或 Codex 的登入資訊。在應用程式中直接連結 ChatGPT 時，只會在這台電腦上保留 OpenAI 發給本應用程式的那一組登入，中斷連結後就刪除。
  • 應用程式中不做登入畫面。登入在該公司自己的畫面上完成。
  • 不會在背景發出你沒有要求的 AI 請求。
  • Claude Code 和 Codex 會在關閉應用程式能關閉的所有工具後執行，關閉應用程式時一併結束。唯一的例外是代理程式視窗：只在你自己選的專案資料夾中，開啟事先定好的工具。

開發者

程式設計代理也能處理同一份文件。

應用程式內附終端機指令 ieumoffice、MCP 伺服器和代理技能。在「設定 → 整合」中註冊後，Claude Code、Codex、Cursor 就能讀取並修改同一個檔案。 

PS> ieumoffice docs read 秋季書展_企劃書.docx
PS> ieumoffice sheet read 書展_預算表.xlsx
PS> ieumoffice open 書展_簡報.pptx

參考的專案
