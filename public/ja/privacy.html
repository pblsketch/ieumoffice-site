プライバシーポリシー

最終更新：2026年10月29日 · 条項別のプライバシーポリシー · 全項目の一覧（英語）： PRIVACY.md

このページは読みやすさのための翻訳です。韓国語の原文と内容が異なる場合は、韓国語の原文が優先します。

IeumOffice は、ユーザーの PC で文書を開き、編集し、保存するデスクトップアプリです。プロジェクトが運営するサーバーがないため、アプリが IeumOffice や作者に送るものは何もありません。利用統計やテレメトリーもありません。

条項別のプライバシーポリシー

韓国の「個人情報保護法」第30条に基づいて定めたポリシーです。韓国の学校で学習支援ソフトウェアの必須基準を確認するとき、この条項番号を根拠として使えます。その下の節は、同じ内容を機能ごとに詳しく説明したものです。

第1条（総則とデータ処理の仕組み）

IeumOffice の開発者（以下「運営者」）は、IeumOffice のプログラムと紹介サイト（ieumoffice.com）を運営するにあたり、利用者の個人情報をこのポリシーに従って取り扱います。

  • IeumOffice はユーザーの PC にインストールして使うデスクトップアプリで、運営者はサーバーを置いていません。会員登録やログインはなく、利用統計・テレメトリーもありません。
  • 文書、設定、AI との会話履歴はユーザーの PC（Windows では %APPDATA%\IeumOffice）にだけ保存され、運営者には送信されません。生徒が書いた文章や生徒の名簿が入った文書を開いても、その内容を運営者が受け取ることはありません。
  • AI 機能を使うと、文書の内容はユーザーが選んだ AI サービス（Anthropic の Claude、OpenAI の ChatGPT・Codex、ユーザーが入力した API キーの提供元など）へ、ユーザー本人のアカウントで PC から直接送信されます。この送信は、利用者がその会社と結んだ契約に基づくもので、運営者はその内容を受け取ることも見ることもできません。文書のうち AI から隠した部分は送信されません。
  • 運営者が直接取り扱う個人情報は、利用者が自分で送った場合に限られます。「フィードバックを送る」のアンケート、メールでのお問い合わせ、紹介サイトの質問アシスタントがこれにあたり、項目は第2条に記載します。GitHub の Issue に書いた内容は GitHub で公開され、GitHub のポリシーに従います。

第3条（取り扱いの目的）

  • 「フィードバックを送る」のアンケート：不具合の確認と再現、機能の改善、メールアドレスが書かれている場合の返信
  • メールでのお問い合わせ：お問い合わせ内容の確認と返信
  • 質問アシスタント：質問に答えること、答えられなかった質問を見つけて案内資料を補うこと

この目的以外には使わず、広告・販売・利用者の分析には使いません。目的が変わる場合は、韓国の「個人情報保護法」第18条に従って別途同意を得るなど、必要な措置をとります。

第4条（保有期間と廃棄）

  • 「フィードバックを送る」のアンケートの回答、メールでのお問い合わせ：返信などの対応を終えた日から1年が過ぎると廃棄します。
  • 質問アシスタントの記録：90日が過ぎると自動で削除します。
  • 利用者から削除の依頼があれば、期間内であっても遅滞なく廃棄します。

廃棄は、アンケート回答シートの行とメールを復元できないよう完全に削除する方法で行います。紙の文書としては保管しません。他の法令によって保存しなければならない情報はありません。

第5条（第三者への提供）

運営者は個人情報を第三者に提供しません。ただし、韓国の「個人情報保護法」第17条・第18条が定める場合（利用者の別途の同意、法律の特別な規定や法令上の義務の遵守など）は例外です。第1条の AI への送信は、利用者本人が選んだサービスへ本人のアカウントから直接送るもので、運営者が提供するものではありません。

第7条（情報主体の権利と行使の方法）

  • 利用者はいつでも、運営者が取り扱う自分の個人情報の閲覧、訂正・削除、取り扱いの停止を求めることができます。pblsketch@gmail.com に依頼してください。依頼を受けた日から10日以内に対応の結果をお知らせします。
  • 法定代理人や委任を受けた人を通じて依頼することもできます。
  • アンケートを送った日時や、質問した日時と内容を知らせていただければ、該当する記録を探して対応します。運営者は名前やアカウント情報を受け取らないため、本人確認にはその情報だけを使います。
  • PC に保存された文書・設定・会話履歴は、利用者が自分で管理します。会話履歴はアプリで削除でき、データフォルダー（%APPDATA%\IeumOffice）を削除するとすべて消えます。

第8条（満14歳未満の児童の個人情報）

  • IeumOffice は、教師を含む成人が仕事に使うために作ったプログラムです。登録の手続きがなく、運営者が生徒の情報を受け取らないため、満14歳未満の児童の個人情報は収集しません。
  • 生徒が書いた文章や生徒の情報が入った文書は、その文書を開いた PC にだけ保存され、運営者には届きません。
  • AI 機能は、利用者が自分で接続した AI 会社のアカウントで動き、その会社が定めた年齢制限に従います（例：Anthropic の Claude は18歳以上）。生徒の情報が入った文書を AI に任せるときは、名前などの識別情報を「AI から隠す」機能で隠すか削除してから使うことをおすすめします。
  • アンケート・メール・質問アシスタントは、成人の利用者のための窓口です。満14歳未満の児童が個人情報を送ったことがわかった場合は、法定代理人の同意を得ていない情報とみなし、遅滞なく廃棄します。

第9条（安全確保のための措置）

  • 管理的措置：取り扱う項目を第2条のものに最小限にとどめ、アンケート回答・メール・質問記録は運営者一人だけが閲覧し、他の人と共有しません。
  • 技術的措置：サイトとアンケート・メール・AI サービスとの間の通信は HTTPS で暗号化されます。質問記録は保存する前にメールアドレス・電話番号・住民登録番号・カード番号の形をした文字列を伏せ、接続元アドレス（IP）を残しません。プログラムは運営者のサーバーに何も送らず、Google ドライブのログイントークンは OS の保護機能で暗号化して PC に保存します。
  • 物理的措置：運営者が自分で運営するサーバーやサーバールームはなく、保管は第6条の委託先のデータセンターの保護体制に従います。

このポリシーを変更するときは、このページに変更内容と施行日を掲載し、いちばん上の最終更新日を書き換えます。変更の履歴はこのページの変更履歴で見られます。この条項別のポリシーは2026年10月29日から施行します。

PC の外に出るもの

データが PC の外に出るのは以下の場合だけで、そのときもユーザーの PC から以下のサービスへ直接送られます。各サービスが受け取ったデータをどう扱うかは、そのサービスの規約と、そこで設定したアカウントの状態に従います。

  • AI との会話。ユーザーが送った文章、リクエストが扱う文書の内容、添付したファイルと画像、スキル（選んだスキルや AI が書いたスキルの内容、AI が自分で使えるようにしたスキルのタイトルと説明）、会話履歴が AI の提供元（ユーザーの Claude・ChatGPT サブスクリプション、ユーザーが選んだ API キーの提供元、または無料接続の OpenRouter・Google）に送られます。どの送信もユーザーのアカウントで直接行われます。
  • 検索・画像。AI や ieumoffice search がウェブを検索すると検索語が検索サービスに、アドレスで画像を挿入するとその画像をホストしているサイトにリクエストが送られます。
  • 新しいバージョンの確認。インストールしたアプリが、公開リリースの一覧を GitHub に問い合わせます。
  • スキルの取り込み。「設定 → スキル」で GitHub のアドレスからスキルを取り込むとき、エージェント画面が提案したインストールを確認するとき、更新の確認を押したときにだけ、その公開リポジトリのファイルを GitHub から受け取ります。ログイン情報は送りません。
  • フィードバックを送る。ユーザーが押したときにだけ、製品のバージョン・OS・表示言語を表示してコピーしてから Google フォームを開きます。文書の内容・パス・アカウントは含めません。
  • Google ドライブ（接続した場合）。以下で別に説明します。

その他の送信経路（OpenRouter の接続、Gemini キーの確認、PDF の AI 読み取り・翻訳、画像生成、画像・動画の分析、Markdown の画像アップロード、作成画面、エージェントモードなど）は、 PRIVACY.mdの表にすべて記載しています。

Google ドライブ

Google ドライブの接続は任意で、「設定 → 連携」でGoogle ドライブに接続を押したときにだけ始まります。ログインは、システムのブラウザーに表示される Google の画面で行います。 IeumOffice はアプリの中に Google のログインフォームを作らず、Google のパスワードを受け取ったり保存したりしません。

IeumOffice が読み取る Google ユーザーデータ

IeumOffice が求めるのは、ユーザーが選んだファイルにだけ届く権限（https://www.googleapis.com/auth/drive.file）ひとつだけです。ユーザーが Google のファイル選択画面で選んだファイルと IeumOffice が作ったファイルだけを開いて編集でき、ドライブのほかのファイルは見られません。この権限で次のものを読み取ります。

  • アカウントの表示：接続したアカウントの名前とメールアドレス。設定画面にどのアカウントが接続されているかを表示するためだけに使います。
  • ファイルの情報：ユーザーが選んだファイルの名前、形式、サイズ、更新日時、チェックサム、親フォルダーの ID、編集できるかどうか。アプリの「選んだファイル」の一覧とその中での検索、AI の検索に使います。
  • ファイルの内容：ユーザーが開いたファイル、AI 画面に添付したファイル、ユーザーがオンにしている場合は AI が読んだファイルの内容。

ドライブに書き込むのは、ユーザーが保存を押したときだけです。そのとき、編集した文書をそのドライブのファイルにアップロードするか、ユーザーが選んだ場合（または Google ドキュメントを Office ファイルとして保存する場合）はその隣かマイドライブに新しいファイルとしてアップロードします。IeumOffice はドライブのファイルを削除・移動・共有せず、Gmail や連絡先など他の Google サービスのデータには触れません。ドライブのデータを集めて統計や匿名データを作ることもしません。

使い道

読み取ったデータは、ユーザーが画面で目にする機能にだけ使います。ファイルの一覧と検索結果の表示、ファイルをエディターで開くこと、編集した文書をドライブに保存すること、そしてユーザーがオンにしている場合に AI が選んだファイルから探して読み、リクエストに答えることです。広告、販売、融資・信用の判断、ユーザーの分析には使わず、IeumOffice が AI モデルを作ったり学習させたりするのにも使いません。プロジェクトにはサーバーがなくドライブのデータを受け取らないため、作者を含め誰もユーザーのドライブのデータを見ません。

誰に渡るのか

  • Google：ドライブへのリクエストは、ユーザーのアカウントでユーザーの PC から Google に直接送られます。
  • ユーザーが選んだ AI の提供元：ユーザーがドライブから開いた文書を AI に任せたとき、ドライブのファイルを AI 画面に添付したとき、AI が選んだファイルを探して読めるようにオンにしたときにだけ、その会話の AI 提供元に、見つかったファイルの一覧と読み取った文章が送られます。提供元は Anthropic（Claude）、OpenAI（ChatGPT・Codex）、ユーザーが入力した API キーの提供元のうちユーザーが選んだところで、送信は PC からユーザーのアカウントで直接行われます。「AI から隠す」で隠した部分は隠したまま送られます。
  • それ以外には誰にも送られません。IeumOffice や作者、広告主、データブローカー、その他の第三者に渡したり売ったりしません。

Google は、ドライブのデータをモデルの学習に使う AI サービスに渡すことを認めていません。そのため IeumOffice は次のようにしています。

  • ドライブを接続する前に、ドライブのファイルと一緒に使う AI アカウントでモデルの学習をオフにしたことを確認してもらいます。オフにする場所も一緒に示します（Claude は「設定 → プライバシー」、ChatGPT・Codex は「設定 → データコントロール」の「すべての人のためにモデルを改善する」）。確認する前は、接続することも、ファイルを選ぶことも、AI にドライブのファイルを渡すこともできません。
  • Anthropic と OpenAI の API（キーの提供元）は、API で受け取った内容を初期設定では学習に使いません。
  • 無料の AI 接続（Gemini、OpenRouter の無料モデル）は学習をオフにできないため、ドライブのファイルを渡しません。無料の接続を使っている間は、ドライブからの添付、AI によるドライブの読み取り、ドライブから開いた文書についての AI へのリクエストがすべて止まります。

保護

  • プロジェクトのサーバーを通らず、PC と Google の間は HTTPS で暗号化されてやり取りされます。
  • ログインには PKCE と、この PC の中でだけ開くアドレス（127.0.0.1）を使い、ほかのプログラムがログインの結果を横取りできないようにしています。
  • ログインを続けるためのトークン（更新トークン）は、OS の保護機能（Windows のユーザーアカウントによる保護、macOS のキーチェーン、 Linux のデスクトップキーリング）で暗号化して保存します。暗号化できない PC では保存しません。アクセストークンはメモリーにだけ置き、エディター画面やログにトークンとファイルの内容を渡しません。
  • AI のドライブ用ツールは読み取り専用です。AI はドライブのファイルを編集・削除・移動・共有することはできません。
  • 文書の中の文章に操られた AI がドライブの内容を外に持ち出せないよう、ドライブの内容が会話に入ったあとは、その会話ではウェブ検索、画像検索、アドレスからの画像の取得、アドレスからのページの読み取りを使いません。

保管と削除

  • ログイントークンは、接続を解除するまでこの PC に置きます。接続を解除を押すとトークンファイルを削除し、 Google にトークンの取り消しを依頼します。Google アカウントのサードパーティとの接続からも、いつでもアクセスを削除できます。
  • ドライブから開いたファイルの PC 上のコピー（データフォルダーの drive-cache）は、1か月開いておらず、アップロードしていない変更がなければ、アプリの起動時に削除します。AI への添付用に受け取ったファイルは1週間後に削除します。
  • AI との会話に入ったドライブの内容はこの PC の会話履歴に残り、その会話を削除すると一緒に消えます。 AI の提供元に送られた内容は、その提供元の保管ポリシーに従います。
  • データフォルダー（Windows では %APPDATA%\IeumOffice）を削除すると、上のものはすべて消えます。プロジェクトはドライブのデータを別に持っていないため、この PC の外で削除するものはありません。

Google API のデータポリシーの遵守

IeumOffice が Google API から受け取った情報の使用と他のアプリへの転送は、 Google API Services User Data Policy（Limited Use の要件を含む）に従います。Google Workspace API から受け取った元のユーザーデータや、そこから派生したデータの使用は Google Workspace API User Data and Developer Policy（Limited Use の要件を含む）に従い、IeumOffice はこのデータを使って汎用の AI・機械学習モデルを開発・改善・学習させることはありません。

PC に残るもの

  • 文書ファイルと、エディターが文書の隣に置く補助ファイル。
  • AI との会話履歴と設定（データフォルダー。Windows では %APPDATA%\IeumOffice）。
  • ドライブのログイン情報（google-drive.json）。OS の保護機能（Windows のユーザーアカウントによる保護、macOS のキーチェーン、Linux のデスクトップキーリング）で暗号化して保存し、接続を解除すると削除します。暗号化を使えない PC では保存せず、アプリを終了すると接続が切れます。
  • ドライブから開いたファイルの PC 上のコピー（データフォルダーの drive-cache）と、AI への添付用の一時フォルダー。
  • ChatGPT をアプリから直接接続した場合はその接続情報（chatgpt-connection.json）。OpenAI がこのアプリに発行したログインと、このインストールと OpenAI アカウントを指す ID です。メールアドレスは保存しません。Windows ではユーザーアカウントによる保護で、Linux ではデスクトップキーリングで暗号化し、Mac とキーリングのない Linux では暗号化せずに保存します。接続を解除すると OpenAI に接続の終了を依頼し、この PC から削除します。Codex プログラムのログインとは別のもので、ChatGPT のパスワードをアプリが目にすることはありません。

何がどこに残り、いつ削除されるかの全項目の一覧も、PRIVACY.md の「What stays on your PC」にあります。

このサイトの質問アシスタント

ここまでは IeumOffice のアプリについての内容です。紹介サイト（ieumoffice.com）の右下にある質問するの画面は、アプリとは別に動きます。この画面で質問を送ると、質問と、同じ画面でそれまでにやり取りした会話（直近の数回分）が、サイトのサーバー関数（Vercel）を通って Anthropic の Claude に送られます。Claude は、IeumOffice のヘルプと案内ページから見つけた内容で回答を書きます。

  • アシスタントが答えられない質問を見つけて案内資料を補うため、質問と回答、根拠にした案内のタイトル、日時をリポジトリの所有者の Google スプレッドシートに90日間保管し、その後削除します。接続元アドレス（IP）やブラウザーの情報は残さず、メールアドレス・電話番号・住民登録番号・カード番号のように見える文字列は保存する前に伏せます。記録はリポジトリの所有者だけが見ます。削除してほしい質問があれば、下記のお問い合わせ先か pblsketch@gmail.com に、送った日時と質問を知らせてください。
  • ブラウザーには何も保存しません。会話はそのページの中にだけあり、ページを閉じると消えます。
  • Anthropic は、API で受け取った入力と出力を初期設定では AI の学習に使わず、30日以内に削除すると説明しています。
  • 短い時間に大量の質問が来るのを防ぐため、サーバーが接続元アドレス（IP）ごとの質問数を一時的に数えます。この数はサーバーのメモリーにだけあり、やがて消えます。
  • 個人情報や文書の内容は書かないでください。
