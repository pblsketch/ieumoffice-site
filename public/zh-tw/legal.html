免費發布與官方下載處

IeumOffice 是免費的。官方下載處只有本網站和 GitHub Releases 兩處。如果有地方收費販售，那不是官方發布。

授權與所依據的專案

IeumOffice 是以 Apache License 2.0 公開的開源軟體。它是以開源辦公軟體 GenOffice（Apache-2.0）為基礎修改而成，Hangul（HWP·HWPX）編輯器則以 rhwp（MIT）為基礎。一併使用的程式與字型之聲明，收錄在 NOTICE 和安裝資料夾中的 THIRD-PARTY-NOTICES.txt；在應用程式中，可到「設定 → 關於 → 開源授權」查看。

本產品參考韓國 Hancom 公司公開的 Hangul 文件檔案（.hwp）格式文件開發而成。

重新發布時

Apache License 2.0 允許任何人修改後重新發布。但必須一併附上 LICENSE 與 NOTICE，並在修改過的檔案中註明已修改。此授權不授予使用商標的權利，因此不能把「이음오피스」、「IeumOffice」、「GenOffice」的名稱與標誌當成自己產品的名稱使用。
