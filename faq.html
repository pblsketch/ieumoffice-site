이음오피스를 쓰다가 막히는 곳을 모았습니다. 0.12.9 기준입니다. 여기에 없는 것은 의견 보내기로 알려 주세요.

지원 환경

휴대폰·모바일 버전·아이패드·안드로이드에서도 쓸 수 있나요?

아닙니다. 이음오피스는 PC에 설치하는 데스크톱 프로그램입니다. 휴대폰(핸드폰), 모바일 버전, 아이폰, 안드로이드, 아이패드, 태블릿에서 쓰는 앱은 없고, 웹 브라우저로 여는 버전도 없습니다. 패드나 모바일 앱으로는 설치할 수 없습니다.

운영체제지원
Windows 10·11 (64비트)정식
macOS (Apple Silicon·Intel)베타
Linux x64 (AppImage·deb·rpm)베타
iPad·iPhone·Android지원하지 않음

Mac (베타)에서도 쓸 수 있나요?

됩니다. Mac은 Apple Silicon과 Intel 모두 베타로 배포합니다. Apple Silicon은 M1 이후, Intel은 0.12.4부터입니다. 설치 파일은 내려받기 페이지에서 고릅니다.

인텔 맥은 언제부터 되나요?

인텔 맥은 0.12.4부터 Apple Silicon과 함께 베타로 배포합니다. 내려받기 페이지에서 인텔 맥용 설치 파일을 고를 수 있습니다. Mac과 Linux는 베타라 개발자가 직접 확인하지 못한 부분이 있고, 사용자 보고로 확인합니다.

Windows 7이나 32비트 Windows에서도 되나요?

지원하지 않습니다. Windows 10·11 64비트만 지원합니다. 32비트 Windows와 Windows 7 이하에서는 설치할 수 없습니다.

비용

정말 무료인가요? 비용은 어떻게 되나요?

프로그램은 무료입니다. 문서 편집·저장에 유료 제한이 없고, 계정이나 구독도 필요 없습니다. 이음오피스가 따로 받는 돈은 없습니다.

AI 기능은 사용자가 이미 쓰는 Claude·ChatGPT 구독이나, 본인이 넣은 API 키로 돌아갑니다. 구독료는 그 회사에 내는 것이고, 이음오피스에 추가로 내는 돈은 없습니다. API 키 (OpenRouter·Gemini)를 쓰면 그 회사에 사용한 만큼 요금이 나갈 수 있고, 무료 한도가 있는 키도 있습니다.

앱이 사용자를 유료 API 키나 종량제 연결로 저절로 바꾸지는 않습니다. 한도가 다 차면 요청을 멈추고 이유를 알려 줍니다.

설치

설치 없이 쓰는 포터블 버전이 있나요?

없습니다. 설치 없이 실행하는 포터블(압축 파일) 버전이나 USB에 넣어 다니는 버전은 아직 만들지 않았습니다.

Windows는 설치 파일(.exe)로 한 번 설치한 뒤 시작 메뉴나 바탕화면에서 실행합니다. Mac은 .dmg를 열어 응용 프로그램 폴더로 옮기고, Linux는 AppImage를 실행하거나 .deb·.rpm으로 설치합니다.

설치가 막히면 설치 도움말에서 지금 보이는 화면을 골라 확인해 보세요.

설치

프로그램은 어떻게 삭제하나요?

Windows는 설정 → 앱 → 설치된 앱에서 IeumOffice를 찾아 제거를 누릅니다. Mac은 Finder → 응용 프로그램에서 IeumOffice를 휴지통으로 옮깁니다. Linux는 설치한 방식에 따라 sudo apt remove ieumoffice, sudo dnf remove ieumoffice를 쓰거나 AppImage 파일을 지웁니다.

제거가 중간에 멈추거나 다시 설치가 안 되면, 같은 버전을 한 번 더 설치한 뒤 제거를 다시 시도해 보세요. 그래도 안 되면 의견 보내기로 어느 화면에서 멈췄는지 알려 주세요.

설정과 최근 문서 기록은 사용자 데이터 폴더에 남을 수 있습니다(Windows %APPDATA%\IeumOffice, Mac ~/Library/Application Support/IeumOffice, Linux ~/.config/IeumOffice). 완전히 지우려면 제거한 뒤 이 폴더를 직접 지웁니다.

설치

처음 켜면 "응답 없음"이나 회색 화면에서 멈춰요

Windows 보안의 제어된 폴더 액세스(랜섬웨어 방지)가 켜진 PC에서 생기던 문제입니다. 이 기능이 문서 폴더에 새 폴더를 만들지 못하게 막아서, 0.12.7까지는 이런 PC에서 앱이 처음 켜질 때 멈출 수 있었습니다. 0.12.8로 업데이트하거나 새로 설치하면 고쳐집니다.

0.12.8부터는 문서 폴더에 쓸 수 없으면 사용자 폴더 아래 IeumOffice 폴더에 새 파일을 저장하고, "문서 폴더에 저장할 수 없습니다" 안내를 한 번 보여 줍니다. 원래대로 문서 폴더에 저장하려면 Windows 보안의 제어된 폴더 액세스를 통해 앱 허용에 이음오피스를 추가한 뒤 앱을 다시 시작합니다. 설정 → 일반 → 저장 위치에서 다른 폴더를 골라도 됩니다.

한글

한글 저장이 안 되고 "저장하지 않았습니다"가 뜹니다

이음오피스는 저장할 때 먼저 새 파일을 쓰고, 그 파일을 다시 읽어 화면과 같은지 확인합니다. 다시 읽은 내용이 화면과 다르면 원본을 덮어쓰지 않고 멈춥니다. 그래서 원본 파일은 그대로 남아 있습니다. 파일이 깨졌다는 뜻이 아니라, 화면과 다른 결과로 원본을 망가뜨리지 않으려고 멈춘 것입니다. 이 검사는 .hwp로 저장할 때만 합니다. .hwpx는 다른 형식이라 이 검사를 하지 않습니다.

  1. 다른 이름으로 저장에서 파일 형식을 HWPX로 바꿔 새 파일에 저장합니다. 저장한 뒤 한컴 한글에서 열어 확인하세요.
  2. 그래도 .hwp로 저장해야 한다면 다른 이름으로 저장에서 HWP를 골라 새 파일에 저장해 봅니다. 같은 검사에 다시 걸릴 수 있습니다.
  3. 안 되면 PDF로 내보내기로 지금 화면의 내용을 보존합니다.
  4. 그래도 안 되면 의견 보내기로 그 문서를 보내 주세요. 개인 정보는 지우거나 바꾼 사본도 괜찮습니다.

앱이 갑자기 꺼졌다면 다음 실행 때 복구본을 제안합니다. 복구본은 사용자 데이터 폴더의 hwp-autosave에 남습니다.

마크다운

마크다운에서 링크를 눌러도 열리지 않아요

마크다운 편집기에서 링크를 그냥 클릭하면 링크 글자를 고칠 수 있도록 커서가 들어갑니다. 링크를 열려면 Ctrl을 누른 채 클릭하세요(Mac은 ⌘을 누른 채 클릭). 발표 화면(F5)처럼 읽기 전용일 때는 그냥 클릭해도 열립니다.

웹 주소(http·https)와 메일 주소(mailto)만 기본 브라우저로 열립니다. 문서 안의 상대 경로, file:// 주소, 원문 보기(Ctrl+E)의 링크는 아직 열리지 않습니다.

링크 위에 마우스를 올리면 손가락 모양이 나와도 편집 중에는 한 번 클릭으로 열리지 않는 것은, 링크 글자를 그 자리에서 고칠 수 있게 하려는 것입니다.

PDF

PDF에 캡처한 이미지를 붙여넣거나 페이지를 복사할 수 있나요?

아직 없습니다. PDF 편집 화면에서 Ctrl+V로 클립보드의 캡처 이미지를 붙여넣는 기능과, 페이지를 한 번에 클립보드로 복사하는 기능은 아직 넣지 않았습니다.

지금은 두 가지 방법을 쓸 수 있습니다.

  • 이미지/도장 삽입으로 캡처를 저장한 이미지 파일을 PDF에 넣습니다.
  • PDF 도구 → 이미지 내보내기로 페이지를 PNG 파일로 저장합니다.

캡처 이미지 붙여넣기와 페이지 복사는 의견 보내기로 요청이 들어와 있습니다. 더 필요하시면 의견 보내기로 알려 주세요.

엑셀

엑셀 파일은 어디까지 호환되나요?

일상적인 .xlsx 작업은 됩니다. 셀 편집, 수식, 서식, 표, 차트(9가지 형식), 피벗 테이블, 조건부 서식, 정렬·필터, 데이터 유효성 검사, 시트·통합 문서 보호를 지원합니다. .csv와 .tsv도 표로 열고 원래 형식으로 저장합니다.

다만 Excel의 모든 기능을 똑같이 지원하지는 않습니다.

  • VBA 매크로는 실행하지 않습니다. .xlsm 파일을 열고 저장할 때 매크로 저장 부분은 지우지 않고 그대로 둡니다.
  • 외부 데이터 연결, 일부 고급 피벗·차트·OLE 개체는 Excel과 결과가 다를 수 있습니다.
  • 저장할 때 결과를 다시 읽어 보고, 읽히지 않으면 원본을 덮어쓰지 않습니다. 중요한 문서는 저장한 뒤 Excel에서 한 번 열어 확인하세요.

호환되지 않는 기능이 있으면 의견 보내기로 파일과 함께 알려 주세요. 개인 정보는 지우거나 바꾼 사본도 괜찮습니다.

엑셀

엑셀에서 행 높이를 같게 하려면 어떻게 하나요?

셀 높이(행 높이)를 같게 하려면 행 머리글(1, 2, 3…)을 여러 개 선택한 뒤 리본의 서식 → 행 높이…를 골라 같은 값을 넣습니다. 그러면 선택한 행의 높이가 같아집니다. 내용에 맞춰 같게 하려면 서식 → 행 높이 자동 맞춤을 씁니다.

열 너비도 같은 방식으로 서식 → 열 너비…에서 맞춥니다. 행 머리글 경계를 끌어서 맞추거나, 경계를 더블클릭해 자동으로 맞출 수도 있습니다.

AI 연결

ChatGPT 요금제로 쓸 수 있나요? Codex 프로그램이 꼭 있어야 하나요?

쓸 수 있고, 0.12.8부터는 Codex 프로그램이 없어도 됩니다. 연결 도우미에서 ChatGPT를 써요를 고르고 ChatGPT로 계속을 누르면 브라우저에 ChatGPT 로그인 화면이 열립니다. 로그인한 뒤 이 앱이 요금제를 쓰도록 허용하면 연결됩니다. 설정 → AI의 ChatGPT 카드에서도 같은 일을 합니다. 화면으로 보려면 AI 연결 도움말을 보세요.

이 PC에서 Codex 프로그램을 이미 쓰고 있다면 Codex로 연결해도 됩니다. 에이전트 모드와 터미널 명령어는 지금처럼 Claude Code나 Codex 프로그램이 있어야 합니다.

사용할 AI가 자동이면 연결된 것 가운데 Claude, ChatGPT, Codex 순서로 고릅니다. 요금이 나가는 API 키나 종량제 로그인은 자동으로 고르지 않습니다.

AI

문서마다 같은 배경 설명을 AI에게 다시 써야 하나요?

0.12.9부터는 프로젝트로 묶으면 됩니다. AI 창 입력란 아래의 프로젝트에서 새 프로젝트를 만들거나 폴더 추가로 쓰던 폴더를 고르세요. 홈의 프로젝트 화면에 적어 둔 지침과 AI가 대화하며 쌓은 기억이 그 프로젝트에서 하는 요청마다 함께 갑니다. AI는 폴더 안 파일을 찾아 읽고, 같은 프로젝트의 대화는 다른 편집기에서도 이어집니다.

지침·기억·대화는 그 폴더 안의 .ieumoffice 폴더에 쌓입니다. AI가 보지 않았으면 하는 파일은 프로젝트 화면의 파일에서 뺄 수 있습니다. 프로젝트를 고르지 않으면 지금처럼 문서마다 따로 대화합니다.

파일

Google 드라이브에 있는 파일을 열 수 있나요?

0.12.9부터 됩니다. 설정 → 연동에서 Google 드라이브를 연결한 뒤 홈의 Google 드라이브에서 고르기를 누르면 Google의 파일 선택 창이 뜹니다. 고른 파일은 탭으로 열리고, 저장하면 드라이브에 다시 올라갑니다. AI 창에서 첨부할 때도 드라이브 파일을 고를 수 있습니다.

앱은 선택 창에서 고른 파일과 앱이 만든 파일만 열고, 드라이브 전체는 보지 않습니다. 드라이브 파일을 AI에 넘기기 전에는 지금 쓰는 AI 계정에서 모델 학습을 껐는지 한 번 확인합니다. 무료 AI 연결에는 드라이브 파일을 넘기지 않습니다.

AI 연결

제미나이(Gemini) 유료 요금제로 연결할 수 있나요?

Gemini Advanced(Google One AI Premium) 구독은 이음오피스의 AI 연결에 직접 쓰이지 않습니다. 무료로 쓰기에서 연결하는 Gemini는 Google AI Studio에서 만든 API 키입니다.

유료 Gemini API 키를 넣으면 사용한 만큼 Google에 요금이 나갈 수 있고, 무료 한도가 있는 키도 있습니다. 앱이 사용자를 유료 API 키로 저절로 바꾸지는 않습니다.

Gemini Advanced 구독을 쓰고 있다면, 지금은 Claude나 ChatGPT 구독을 연결하거나 Google AI Studio에서 API 키를 만들어 연결해야 합니다.

라이선스

회사·기업·기관에서 업무용으로 써도 되나요?

됩니다. 이음오피스는 Apache License 2.0으로 배포하는 무료 오픈소스입니다. 회사(기업), 학교, 공공기관에서도 별도 구독 없이 업무용으로 쓸 수 있고, 문서 편집·저장 기능에 유료 제한은 없습니다.

AI 기능은 각 사용자의 Claude·ChatGPT 구독이나 본인이 넣은 API 키로 돌아갑니다. 회사 계정으로 관리하려면 그 회사의 약관을 확인하세요. 앱은 사용 통계를 보내지 않고, 문서는 PC에 남습니다.

라이선스 전문은 GitHub의 LICENSE에 있습니다.

한글

한컴 한글과 무엇이 다른가요?

이음오피스의 한글 편집기는 .hwp와 .hwpx를 열고 저장하며, 글자·표·스타일·단축키 등 기본 편집을 할 수 있습니다. 한컴 한글(아래한글) 2024의 단축키를 많이 맞췄고, AI로 문서를 고치거나 PDF로 내보낼 수도 있습니다.

한컴오피스의 모든 기능을 똑같이 재현하지는 않습니다. 변경 내용 추적은 현재 내용으로 열리고 추적 기록은 저장되지 않습니다. 일부 개체·필드·쪽 배치는 한글과 다를 수 있습니다.

중요한 문서는 이음오피스에서 저장한 뒤 한컴 한글에서 한 번 열어 확인하세요.

AI 연결

로컬 LLM으로 쓸 수 있나요?

됩니다(0.12.6부터). 이음오피스가 모델을 직접 돌리지는 않고, 내 PC나 사내망에서 돌리는 AI 서버(Ollama 등)에 연결합니다. 설정 → AI의 로컬 AI에서 서버 주소를 등록하고, 연결 테스트로 대화가 되는지 확인합니다.

등록만 해서는 쓰는 AI가 바뀌지 않고, 직접 고른 서버만 씁니다. 서버 주소가 PC 밖 인터넷 주소이면 문서가 그쪽으로 간다고 알려 줍니다. 인터넷 없이도 문서 편집과 저장은 할 수 있습니다.

AI

AI가 "올바른 호출을 다시 보냅니다"라고 합니다

AI가 문서를 고치는 도구를 잘못된 형식으로 보내면, 앱이 그 요청을 다시 보내 달라고 안내합니다. 잠시 기다리면 다시 답할 때가 많습니다.

같은 요청에서 계속 반복되면 요청을 조금 바꿔 보거나, 어떤 요청이었는지 의견 보내기로 알려 주세요. 화면과 대화 기록을 함께 보내 주시면 찾기 쉽습니다.

업데이트

업데이트 소식을 이메일로 받을 수 있나요?

이메일이나 문자로 업데이트 소식을 보내는 서비스는 없습니다. 이음오피스는 이메일 주소를 받지 않습니다.

새 버전은 앱이 4시간마다 확인합니다. 탭 줄의 ☰ 메뉴 → 업데이트 확인…(Mac은 도움말 → 업데이트 확인…)으로 바로 확인할 수 있고, 새 버전이 있으면 앱 안에서 알려 줍니다. 저절로 확인하지 않게 하려면 설정 → 정보에서 자동으로 업데이트 확인을 끕니다. GitHub Releases 페이지에서도 내려받을 수 있습니다.

GitHub에서 새 릴리스 알림을 받고 싶다면 저장소의 Watch → Custom → Releases를 고르면 됩니다.

여기에 없는 질문은 의견 보내기로 알려 주세요. 어느 화면에서 막혔는지, 무엇을 하려 했는지 적어 주시면 더 빨리 찾을 수 있습니다.
