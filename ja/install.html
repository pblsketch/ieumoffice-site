Windows 11

「スマート アプリ コントロールによりブロックされました」と表示される

新しく買ったノート PC や、Windows を新しくインストールした PC でよく出る画面です。IeumOffice は無料で配布しているプログラムなので、Windows が発行元を確認できる署名がありません。そのため、インストールするときだけでなく、実行するときも Windows 11 が止めます。この画面には 実行 ボタンもなく、このプログラムだけを個別に許可する方法もありません。スマート アプリ コントロールをオフにすれば、インストールと実行ができます。ただし、もう一度オンにすると IeumOffice が止められるので、 IeumOffice を使っている間はオフのままにしておく必要があります。

  1. ブロックの画面が出たら OK を押して閉じます。
  2. スタート ボタンの横の検索に Windows セキュリティ と入力して開き、左側の アプリとブラウザー コントロール を押します。
  3. スマート アプリ コントロールの設定 を押します。
  4. オフ を選びます。これで、ダウンロードしたインストーラーをもう一度開くとインストールが始まります。

スマート アプリ コントロールは、インターネットから入手した見慣れないプログラムを止める機能です。オフにするとその保護は弱くなりますが、 IeumOffice を使えるようになります。Windows セキュリティのウイルスと脅威の防止（Defender）はオンのまま残るので、ウイルスのスキャンは続きます。あとでもう一度オンにすると、IeumOffice は実行できなくなります。

オフにしたあとで青い「Windows によって PC が保護されました」の画面が続けて出たら、その画面では 詳細情報 → 実行 を押せば大丈夫です。手順は 「Windows によって PC が保護されました」と表示されるにあります。

Microsoft Store からアプリを入手 を押しても IeumOffice は出てきません。Store には公開していないプログラムです。PC によっては「一度オフにすると元に戻せない」という案内が出ます。オフにする前に読んでください。設定を変えたあとも止められる場合は、PC を一度再起動してみてください。会社や学校から渡された PC では、この設定を変えられないことがあるので、PC を管理している人に伝えてください。画面は説明のために描き直したものなので、Windows のバージョンによって少し違うことがあります。

Mac と Linux でインストールするとき

Mac で初めて開くとき ベータ

macOS 12 以降で使えます。アップルメニュー → この Mac について でチップを確認してください。Apple M で始まっていれば Apple Silicon 用のファイルを、Intel なら Intel 用のファイルをダウンロードします。Apple の開発者署名がない無料のベータ版なので、最初の 1 回だけ自分で許可します。

  1. ダウンロードした .dmg を開き、IeumOffice を アプリケーション フォルダーにドラッグします。
  2. アプリケーション フォルダーから IeumOffice を開きます。警告が出たら 完了 を押します。
  3. システム設定 → プライバシーとセキュリティ を開き、下のほうにある「“IeumOffice”の使用はブロックされました」の横の このまま開く を押して、Mac のパスワードを入力します。
  4. もう一度出る画面で 開く を押します。次回からはすぐに開きます。

「“IeumOffice”は壊れているため開けません」と表示されたら、ゴミ箱に入れずに、ターミナルで下の 1 行を実行してからもう一度開きます。

xattr -dr com.apple.quarantine /Applications/IeumOffice.app

0.12.11 からは、アプリケーション フォルダーに置いたアプリは、アップデートの画面で 今すぐ更新 → 再起動してインストール を押すと新しいバージョンに替わり、もう一度開きます。0.12.10 以前を使っている場合は、今回だけここから 0.12.11 をダウンロードして上書きインストールしてください。ディスクイメージから直接開いたアプリでは、アップデートの画面がダウンロードページを開きます。アプリが自動で替わらない場合は、ここからもう一度ダウンロードして上書きインストールすれば大丈夫です。 Claude Code や Codex は、AI の接続カードの「公式のインストール手順」に沿ってインストールします（Mac での AI の接続）。

  • Apple Silicon 版をダウンロード — Apple Silicon · ベータ
  • Intel Mac 版をダウンロード — Intel · ベータ
Linux でインストールするとき ベータ

64 ビット（x86_64）の Linux 向けに 3 種類のファイルを用意しています。使っているディストリビューションに合うものを選んでダウンロードしてください。

  • AppImage — インストールせずに、実行権限（chmod +x）を付けるだけですぐに開けます。自動でアップデートします。
  • .deb パッケージ — Ubuntu・Debian 系：sudo apt install ./ieumoffice_*_amd64.deb
  • .rpm パッケージ — Fedora・RHEL・openSUSE 系：sudo dnf install ./ieumoffice-*.x86_64.rpm

.deb と .rpm は /opt/IeumOffice にインストールされ、ターミナルのコマンド /usr/bin/ieumoffice をリンクします。新しいバージョンが出るとアプリが知らせ、 AppImage はアプリの中でそのままアップデートされます。Claude Code や Codex は、AI の接続カードの「公式のインストール手順」に沿ってインストールします。

それでもうまくいかない場合は、フィードバックを送るから、どの画面でつまずいたかを教えてください。その画面のスクリーンショットも一緒に送っていただくと、早く原因を見つけられます。
