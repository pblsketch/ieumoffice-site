ハングル

ハングルのファイルは
ハングルのファイルのまま。

公文書や申請書のように、ハングル（HWP）のファイルでやり取りする文書を開いて編集します。編集が終わったら元の形式のまま保存し、PDF にしたり、そのまま印刷したりできます。

元の形式で保存します
.hwp は .hwp のまま、.hwpx は .hwpx のまま保存します。ファイルを初めて上書きするときは、元のファイルを .bak として残します。名前を付けて保存するときは、2 つの形式から選ぶか、PDF でコピーを作れます。
Hancom Hangul でもう一度開けます
編集して保存したファイルが Hancom Hangul 2024 で開けるかどうか、実際のハングル文書数百件で確かめながら作りました。
新しい文書と PDF
空のハングル文書をホームから新しく作り、書き終えた文書は PDF にしたり、そのまま印刷したりします。PDF エディターの「PDF 変換」→「HWP に変換」を押せば、PDF をハングル文書として取り込んで編集することもできます。
繰り返しの作業は AI ウィンドウに
表のセルを埋める、行や列を追加・削除する、フォームフィールドに入力する、脚注や目次を入れる、といった作業を頼めます。

ハングルの編集画面は、オープンソースの rhwp で作りました。

AI

必要なときだけ
AI に任せます。

エディターの隣に AI ウィンドウがあります。使わなくても、オフィスとして使うのに支障はありません。表を埋めたり文章を整えたりといった手間のかかる作業を任せたいときに頼むと、AI がアプリの編集ツールで開いている文書を直します。よく頼む作業はスキルとして保存しておき、入力欄に / を打って呼び出せます。

画面内の会話は説明のための例です。

元に戻せます
AI が何を変えたかを示し、気に入らなければ元に戻します。
資料から新しい文書を作ります
選んだファイルを読んで、プレゼン資料、HTML ページ、マインドマップを作ります。
自分の文書に質問します
ホームでスターを付けたファイルを選んで質問すると、それらのファイルを読んで答えます。

費用

AI を使っても、追加の費用はかかりません。

IeumOffice は、すでに使っている Claude や ChatGPT のサブスクリプションで回答を受け取ります。リクエストは自分のサブスクリプションの利用上限から差し引かれ、API キーを別に作る必要はありません。

既定

サブスクリプション

Claude のサブスクリプション（Claude Code）、ChatGPT のプラン

サブスクリプション料金のほかにはかかりません。サブスクリプションの利用上限から差し引かれます。

サブスクリプションがないとき

無料の AI

OpenRouter、Google Gemini

無料枠の範囲ではかかりません。設定で接続します。

自分で選んだときだけ

使った分だけ払う方式

API キー、従量課金のアカウント

使った分をその会社に支払います。

サブスクリプションの上限に達すると、リクエストを止めて理由を知らせます。再び使える時刻がわかる場合は、それも知らせます。料金が発生する接続に勝手に切り替えることはありません。

個人情報

サーバーもアカウントもありません。

IeumOffice は利用統計を送らず、文書は自分の PC で開いて保存します。PC の外に出るのは、AI に頼むときにその AI の会社へ送る内容です。

プライバシーポリシーの全文を見る
  • Claude Code や Codex のログイン情報を読んだり、コピーしたり、保存したりしません。ChatGPT をアプリから直接接続すると、OpenAI がこのアプリに発行したログイン情報ひとつだけをこの PC に置き、接続を解除すると削除します。
  • アプリの中にログイン画面を作りません。ログインはその会社の画面で完結します。
  • 頼んでいない AI リクエストを裏で始めることはありません。
  • Claude Code と Codex は、アプリがオフにできるツールをすべてオフにしたまま実行し、アプリを閉じると一緒に終了させます。エージェントウィンドウだけは例外で、自分で選んだプロジェクトフォルダーで、決められたツールだけをオンにします。

開発者向け

コーディングエージェントも同じ文書を。

アプリにはターミナルのコマンド ieumoffice と MCP サーバー、エージェントスキルが入っています。設定 → 連携で登録すると、Claude Code、Codex、Cursor が同じファイルを読んで編集します。 

PS> ieumoffice docs read 秋のブックフェア_企画書.docx
PS> ieumoffice sheet read ブックフェア_予算表.xlsx
PS> ieumoffice open ブックフェア_発表.pptx

インストール

インストールは 3 ステップ。

  1. インストーラーをダウンロード

    下のボタンから IeumOffice-Setup.exe をダウンロードします。64 ビット版 Windows 10 と 11 用です。

  2. 警告が出たら

    新しく出た無料のプログラムなので、Windows が警告を出すことがあります。止められたら、下でいま見えている画面を選んでください。どこを押せばよいかをお見せします。

  3. AI を接続

    初回起動時の案内で Claude や ChatGPT のサブスクリプションを接続します。サブスクリプションがなければ無料の AI を接続します。つまずいたら AI 接続のヘルプをご覧ください。
