AI 接続のヘルプ

AI を接続

IeumOffice の AI は、いま使っている Claude や ChatGPT のサブスクリプションで動きます。サブスクリプションがなければ、無料の AI を接続すれば使えます。下から自分に合うものを選ぶと、どこを押すかをマウスポインターが実際に動いてお見せします。

いま使っている AI はありますか？

Claude の有料サブスクリプションがあります Pro または Max プラン ChatGPT を使っています プログラムなしで、ログインするだけで接続 まだありません 無料の AI を 1 分ほどで接続 接続の途中でつまずいた ログインで止まる、バージョンが古い など

接続の画面は 3 か所にあります。初回起動時の案内の AI を接続 のステップ、AI がひとつも接続されていない AI ウィンドウ、そしてホームの左下の 設定 → AI です。どこから始めても手順は同じです。

Claude のサブスクリプション

Claude のサブスクリプションで接続する

Claude の Pro または Max プランが必要です。無料の Claude アカウントでは接続できません。IeumOffice は PC にインストールした Claude Code というプログラムを通して回答を受け取るので、最初に 1 回だけそのプログラムをインストールしてログインします。API キーは不要です。

  1. AI ウィンドウに「いま使っている AI はありますか？」と表示されたら、ChatGPT を使っています を押します。
  2. カードに「未ログイン」と表示されていたら ChatGPT で続行 を押します。ブラウザーで ChatGPT のログイン画面が開きます。

画面は説明のために簡単に描き直したものです。ブラウザーのログイン画面は OpenAI のものなので、実際の見た目やボタンの名前が違うことがあります。エージェントモードとターミナルのコマンドは、直接接続した ChatGPT を使いません。そちらでも ChatGPT のプランを使うには、下のように Codex プログラムで接続してください。

つまずいたとき

接続の途中でつまずいたとき

カードに表示されている言葉を探して開いてみてください。

「ログイン中…」のまま止まる

ブラウザーにログイン画面が出ているなら、そこでログインして許可を押せば大丈夫です。時間がかかってもかまいません。このときはカードの下のリンクや ログインウィンドウを開く ボタンを押さないでください。押すと、進めていたログインが止まり、最初からやり直しになります。

ブラウザーがまったく開かなかった場合は、次のようにします。

  1. カードの下のリンクか、25 秒たつと出る ログインウィンドウを開く ボタンを押します。黒いウィンドウがひとつ開きます。このときブラウザーが開いたら、そこでログインして許可を押してください。ウィンドウが自動で閉じて接続されます。
  2. それでもブラウザーが開かない場合は、黒いウィンドウに表示された https:// で始まるアドレスをマウスでドラッグして選択し、右クリックしてコピーします。ブラウザーのアドレスバーに貼り付けると、ログイン画面が開きます。
  3. ログインして許可を押すと、ブラウザーにコードが表示されます。コード全体をコピーします。コピーボタンがあれば、それを押してください。
  4. 黒いウィンドウの中で 一度 右クリックして貼り付け、Enter を押します。貼り付けたコードがウィンドウに表示されなくても正常です。
  5. ウィンドウが閉じて、カードが「接続済み」に変われば完了です。

ウィンドウに Invalid code と表示されたら、コードが最後までコピーされていません。コードの途中に # があり、その前後が両方とも入っている必要があります。ウィンドウを閉じずに、コードをもう一度コピーして同じウィンドウに貼り付けてください。

最初からやり直すには、カードの ログインをキャンセル を押してから、ログイン をもう一度押します。

ChatGPT のカード（直接接続）には黒いログインウィンドウはありません。ブラウザーでログインし、許可まで済ませてください。ブラウザーが開かなかったか、やり直したい場合は、ログインをキャンセル を押してから ChatGPT で続行 をもう一度押します。

「ログインが完了していません」と表示される

ブラウザーがログインを終えず、コードだけを表示したまま止まると、この案内が出ます。そのコードは、アプリではなくログインウィンドウに貼り付ける必要があります。すでに表示されたコードは使えないので、最初からログインし直します。

  1. カードの ログインウィンドウを開く ボタンを押します。黒いログインウィンドウが開きます。ウィンドウではなくブラウザーでやり直すには、ブラウザでやり直す を押します。
  2. 上の 「ログイン中…」のまま止まるの 2〜5 と同じように、ブラウザーでログインしてから、表示されたコードをそのウィンドウに貼り付けます。

まだログインしていないカードにも ブラウザにコードが表示されましたか？ のリンクがあるので、最初からこのウィンドウでログインすることもできます。このログインウィンドウは Windows でのみ使えます（IeumOffice 0.12.7 から）。

ChatGPT のカードで「ログインが完了していません」と表示された場合は、このアプリに ChatGPT のプランの使用を許可しなかったか、 10 分以内にログインを終えられなかったということです。ログインウィンドウは不要で、ChatGPT で続行 をもう一度押せば最初から始まります。

「プログラムが古すぎます」と表示される

PC にある Claude Code や Codex が古いバージョンです。カードの 更新 を押すと、その会社の公式の更新が新しいウィンドウで実行されます。そのウィンドウで更新が終わったら IeumOffice に戻ってください。アプリが自動でもう一度確認します。

カードに「このアプリが実行するファイル」も表示されている場合は、まさにそのファイルを更新する必要があります。WSL（Ubuntu）や別のフォルダーにインストールされたコピーを更新しても、このファイルは変わりません。更新ボタンがない場合は、Windows PowerShell でカードに書かれたコマンドを実行します。

「ログイン済みですが、サブスクリプションではありません」と表示される

プログラムが、サブスクリプションのアカウントではなく、API キーや使った分だけ料金を払うアカウントでログインしています。このとき それでも使用 を押すと、リクエストのたびにそのアカウントに料金がかかります。押すまでは、IeumOffice はその接続を使いません。

サブスクリプションで使うには、設定 → AI のカードで 別のアカウントでログイン を押し、サブスクリプション中のアカウントでログインし直してから再確認 を押します。

「接続を確認できませんでした」と表示される

プログラムから時間内に応答がなかったか、確認の途中で問題が起きた場合です。しばらくしてから 再確認 を押します。会社や学校のように、プロキシを通してインターネットに出る PC では、PowerShell で claude や codex が動くかを先に確かめてください。そこで動かなければ、IeumOffice でも動きません。

Claude の無料アカウントしかない

Claude は Pro か Max のプランでないと接続できません。無料アカウントでログインしても接続されません。サブスクリプションに加入するつもりがなければ、無料の AI を接続してください。カードの 別の方法を選ぶ を押すと、最初の質問に戻ります。

Mac で接続するとき ベータ

Mac では、カードに インストール ボタンの代わりに 公式のインストール手順 が表示されます。押すとその会社のインストールの説明が開くので、そこに書かれているとおりにターミナルで Claude Code や Codex をインストールします。インストールしてから IeumOffice に戻ると、カードが「未ログイン」に変わり、そのあとは Windows と同じです。ログイン を押して、ブラウザーでログインすれば完了です。

古いバージョンと表示されたら、ターミナルでカードに書かれた更新のコマンドを実行します。

ChatGPT を直接接続する場合は、インストールするプログラムがないので、Mac でも Windows と同じ手順です。

それでもうまくいかない場合は、接続画面の下のほうにある サポート用の情報をコピー を押してから、フィードバックを送るに貼り付けて送ってください。コピーされるのは接続の状態とプログラムのバージョンだけで、アカウントとファイルのパスは含まれません。

IeumOffice は Claude Code や Codex のログイン情報を読んだり保存したりしません。ログインはその会社のプログラムと Web ページでのみ行い、ChatGPT のパスワードも IeumOffice は見ません。ChatGPT を直接接続すると、OpenAI がこのアプリに発行したログイン情報ひとつだけをこの PC に置き（Windows では暗号化して保存します）、接続を解除すると OpenAI に接続の終了を求めてから削除します。サブスクリプションの上限に達したら、リクエストを止めて知らせるだけで、料金が発生する接続に勝手に切り替えることはありません。

IeumOffice はオープンソースプロジェクト GenOffice（Apache-2.0）をもとに手を加えて作ったプログラムで、ハングルエディターは rhwp（MIT）をもとにしています。このサイトのフォントは Wanted Sans と Gowun Batang（SIL OFL 1.1）です。

Claude は Anthropic の、ChatGPT と Codex は OpenAI の商標です。IeumOffice は両社と関係がありません。
