よくある質問

IeumOffice を使っていてつまずきやすいところをまとめました。0.12.12 時点の内容です。ここにないことは フィードバックを送るからお知らせください。

対応環境

スマートフォン・モバイル版・iPad・Android でも使えますか？

いいえ。IeumOffice は PC にインストールするデスクトップのプログラムです。スマートフォン（携帯電話）、モバイル版、iPhone、Android、iPad、タブレットで使うアプリはなく、Web ブラウザーで開く版もありません。タブレットやモバイルのアプリとしてはインストールできません。

OS対応
Windows 10・11（64 ビット）正式
macOS（Apple Silicon・Intel）ベータ
Linux x64（AppImage・deb・rpm）ベータ
iPad・iPhone・Android非対応

Mac（ベータ）でも使えますか？

使えます。Mac は Apple Silicon と Intel のどちらもベータ版として配布しています。Apple Silicon は M1 以降、 Intel は 0.12.4 からです。インストーラーはダウンロードページで選びます。

Intel Mac はいつから使えますか？

Intel Mac は 0.12.4 から、Apple Silicon と一緒にベータ版として配布しています。ダウンロードページで Intel Mac 用のインストーラーを選べます。Mac と Linux はベータ版なので、開発者が直接確かめられていない部分があり、利用者からの報告で確認しています。

Windows 7 や 32 ビット版 Windows でも使えますか？

対応していません。対応しているのは Windows 10・11 の 64 ビット版だけです。32 ビット版 Windows と Windows 7 以前にはインストールできません。

費用

本当に無料ですか？ 費用はどうなっていますか？

プログラムは無料です。文書の編集・保存に有料の制限はなく、アカウントやサブスクリプションも必要ありません。IeumOffice が別にお金を受け取ることはありません。

AI 機能は、すでに使っている Claude・ChatGPT のサブスクリプションか、自分で入力した API キーで動きます。サブスクリプション料金はその会社に払うもので、IeumOffice に追加で払うお金はありません。API キー（OpenRouter・Gemini）を使うと、その会社に使った分の料金がかかることがあり、無料枠のあるキーもあります。

アプリが勝手に有料の API キーや従量課金の接続に切り替えることはありません。上限に達すると、リクエストを止めて理由を知らせます。

インストール

インストールせずに使えるポータブル版はありますか？

ありません。インストールせずに実行するポータブル版（圧縮ファイル）や、USB メモリに入れて持ち歩く版は、まだ作っていません。

Windows では、インストーラー（.exe）で一度インストールしてから、スタートメニューやデスクトップから起動します。 Mac は .dmg を開いてアプリケーション フォルダーに移し、Linux は AppImage を実行するか、 .deb・.rpm でインストールします。

インストールでつまずいたら、インストールのヘルプで、いま見えている画面を選んで確かめてください。

インストール

プログラムはどうやって削除しますか？

Windows では 設定 → アプリ → インストールされているアプリ で IeumOffice を探し、アンインストール を押します。 Mac では Finder → アプリケーション で IeumOffice をゴミ箱に移します。Linux では、インストールした方法に合わせて sudo apt remove ieumoffice、 sudo dnf remove ieumoffice を使うか、AppImage のファイルを削除します。

アンインストールが途中で止まったり、もう一度インストールできなかったりする場合は、同じバージョンをもう一度インストールしてから、アンインストールをやり直してみてください。それでもだめなら、フィードバックを送るからどの画面で止まったかを教えてください。

設定と最近使った文書の記録は、ユーザーデータのフォルダーに残ることがあります（Windows %APPDATA%\IeumOffice、Mac ~/Library/Application Support/IeumOffice、Linux ~/.config/IeumOffice）。完全に消すには、アンインストールしたあとでこのフォルダーを自分で削除します。

インストール

初めて起動すると「応答なし」や灰色の画面で止まります

Windows セキュリティの コントロールされたフォルダー アクセス（ランサムウェア防止）がオンになっている PC で起きていた問題です。この機能がドキュメント フォルダーに新しいフォルダーを作らせないため、0.12.7 までは、こうした PC でアプリが初めて起動するときに止まることがありました。 0.12.8 に更新するか、新しくインストールすれば直ります。

0.12.8 からは、ドキュメント フォルダーに書き込めない場合、ユーザー フォルダーの下の IeumOffice フォルダーに新しいファイルを保存し、「ドキュメント フォルダーに保存できません」という案内を一度表示します。これまでどおりドキュメント フォルダーに保存するには、Windows セキュリティの コントロールされたフォルダー アクセスによるアプリの許可 に IeumOffice を追加してから、アプリを再起動します。設定 → 一般 → 保存先 で別のフォルダーを選んでもかまいません。

ハングル

ハングル（HWP）の保存ができず、「保存しませんでした」と表示されます

IeumOffice は保存するとき、まず新しいファイルを書き出し、そのファイルを読み直して画面と同じかどうかを確かめます。読み直した内容が画面と違えば、元のファイルを上書きせずに止まります。そのため元のファイルはそのまま残っています。 ファイルが壊れたという意味ではなく、画面と違う結果で元のファイルを壊さないように止めたのです。この確認は .hwp で保存するときだけ行います。.hwpx は別の形式なので、この確認は行いません。

  1. 名前を付けて保存 でファイルの種類を HWPX に変えて、新しいファイルに保存します。保存したら、Hancom Hangul で開いて確かめてください。
  2. それでも .hwp で保存する必要がある場合は、名前を付けて保存 で HWP を選んで新しいファイルに保存してみます。同じ確認でまた止まることがあります。
  3. だめなら、PDF として書き出す でいまの画面の内容を残します。
  4. それでもだめなら、フィードバックを送るからその文書を送ってください。個人情報を消したり置き換えたりしたコピーでもかまいません。

アプリが突然終了した場合は、次に起動したときに復元用のコピーを提案します。復元用のコピーはユーザーデータのフォルダーの hwp-autosave に残ります。

Markdown

Markdown でリンクをクリックしても開きません

Markdown エディターでリンクを 普通にクリック すると、リンクの文字を直せるようにカーソルが入ります。リンクを開くには Ctrl を押しながらクリック してください（Mac では ⌘ を押しながらクリック）。プレゼンテーション表示（F5）のような読み取り専用のときは、普通にクリックしても開きます。

既定のブラウザーで開くのは、Web アドレス（http・https）とメールアドレス（mailto）だけです。文書の中の相対パス、file:// のアドレス、ソース表示（Ctrl+E）のリンクは、まだ開きません。

リンクにマウスポインターを合わせると指の形になるのに、編集中は 1 回のクリックで開かないのは、リンクの文字をその場で直せるようにするためです。

PDF

PDF にスクリーンショットの画像を貼り付けたり、ページをコピーしたりできますか？

まだできません。PDF の編集画面で Ctrl+V でクリップボードのスクリーンショット画像を貼り付ける機能と、ページをまとめてクリップボードにコピーする機能は、まだ入れていません。

いまは次の 2 つの方法が使えます。

  • 画像/スタンプの挿入 で、スクリーンショットを保存した画像ファイルを PDF に入れます。
  • PDF ツール → 画像を書き出す で、ページを PNG ファイルとして保存します。

スクリーンショット画像の貼り付けとページのコピーは、フィードバックで要望が届いています。さらに必要な場合は、フィードバックを送るからお知らせください。

Excel

Excel のファイルはどこまで互換性がありますか？

日常的な .xlsx の作業はできます。セルの編集、数式、書式、テーブル、グラフ（9 種類）、ピボットテーブル、条件付き書式、並べ替え・フィルター、データの入力規則、シート・ブックの保護に対応しています。.csv と .tsv も表として開き、元の形式で保存します。

ただし、Excel のすべての機能に同じように対応しているわけではありません。

  • VBA マクロ は実行しません。.xlsm ファイルを開いて保存するとき、マクロが保存されている部分は消さずにそのまま残します。
  • 外部データ接続、一部の高度なピボット・グラフ・OLE オブジェクトは、Excel と結果が違うことがあります。
  • 保存するときは結果を読み直し、読めなければ元のファイルを上書きしません。大切な文書は、保存したあとで一度 Excel で開いて確かめてください。

互換性のない機能があれば、フィードバックを送るからファイルと一緒にお知らせください。個人情報を消したり置き換えたりしたコピーでもかまいません。

Excel

Excel で行の高さをそろえるにはどうすればいいですか？

セルの高さ（行の高さ）をそろえるには、行番号（1、2、3…）を複数選んでから、リボンの書式 → 行の高さ… を選んで同じ値を入れます。これで、選んだ行の高さがそろいます。内容に合わせてそろえるには 書式 → 行の高さの自動調整 を使います。

列の幅も同じように 書式 → 列の幅… でそろえます。行番号の境界をドラッグして合わせたり、境界をダブルクリックして自動で合わせたりもできます。

AI の接続

ChatGPT のプランで使えますか？ Codex プログラムは必要ですか？

使えます。0.12.8 からは Codex プログラムがなくても大丈夫です。接続の案内で ChatGPT を使っています を選び、ChatGPT で続行 を押すと、ブラウザーで ChatGPT のログイン画面が開きます。ログインして、このアプリがプランを使うことを許可すれば接続されます。設定 → AI の ChatGPT のカードでも同じことができます。画面で見るには AI 接続のヘルプをご覧ください。

この PC で Codex プログラムをすでに使っているなら、Codex で接続してもかまいません。エージェントモードとターミナルのコマンドには、これまでどおり Claude Code か Codex のプログラムが必要です。

使用する AI が 自動 なら、接続されているものの中から Claude、ChatGPT、Codex の順に選びます。料金が発生する API キーや従量課金のログインは、自動では選びません。

AI

文書ごとに同じ背景の説明を AI に書き直す必要がありますか？

0.12.9 からは、プロジェクトにまとめれば済みます。AI ウィンドウの入力欄の下にある プロジェクト で 新しいプロジェクト を作るか、フォルダーを追加 で使っていたフォルダーを選んでください。ホームの プロジェクト 画面に書いておいた指示と、AI が会話の中で積み重ねた記憶が、そのプロジェクトでのリクエストのたびに一緒に送られます。AI はフォルダー内のファイルを探して読み、同じプロジェクトの会話は別のエディターでも続きます。

指示・記憶・会話は、そのフォルダーの中の .ieumoffice フォルダーにたまります。AI に見せたくないファイルは、プロジェクト画面の ファイル で外せます。プロジェクトを選ばなければ、これまでどおり文書ごとに別々に会話します。

ファイル

Google ドライブにあるファイルを開けますか？

0.12.9 から開けます。設定 → 連携 で Google ドライブを接続してから、ホームの Google ドライブから選ぶ を押すと、Google のファイル選択画面が開きます。選んだファイルはタブで開き、保存するとドライブにアップロードし直されます。AI ウィンドウで添付するときも、ドライブのファイルを選べます。

アプリが開くのは、選択画面で選んだファイルとアプリが作ったファイルだけで、ドライブ全体は見ません。ドライブのファイルを AI に渡す前には、いま使っている AI のアカウントでモデルの学習をオフにしているかを一度確認します。無料の AI の接続には、ドライブのファイルを渡しません。

AI の接続

Gemini の有料プランで接続できますか？

Gemini Advanced（Google One AI Premium）のサブスクリプションは、IeumOffice の AI の接続には直接使えません。「無料で使う」で接続する Gemini は、Google AI Studio で作成した API キー です。

有料の Gemini API キーを入れると、使った分の料金が Google から請求されることがあり、無料枠のあるキーもあります。アプリが勝手に有料の API キーに切り替えることはありません。

Gemini Advanced のサブスクリプションを使っている場合は、いまのところ Claude か ChatGPT のサブスクリプションを接続するか、 Google AI Studio で API キーを作成して接続する必要があります。

ライセンス

会社・企業・機関で業務に使ってもいいですか？

かまいません。IeumOffice は Apache License 2.0 で配布している無料のオープンソースです。会社（企業）、学校、公共機関でも、別途サブスクリプションなしで業務に使えます。文書の編集・保存の機能に有料の制限はありません。

AI 機能は、各利用者の Claude・ChatGPT のサブスクリプションか、自分で入力した API キーで動きます。会社のアカウントで管理する場合は、その会社の利用規約を確認してください。アプリは利用統計を送らず、文書は PC に残ります。

ライセンスの全文は GitHub の LICENSE にあります。

ハングル

Hancom Hangul とは何が違いますか？

IeumOffice のハングルエディターは .hwp と .hwpx を開いて保存し、文字・表・スタイル・ショートカットキーなどの基本的な編集ができます。Hancom Hangul 2024 のショートカットキーに多く合わせてあり、AI で文書を直したり、PDF に書き出したりもできます。

Hancom Office のすべての機能を同じように再現しているわけではありません。変更履歴は現在の内容で開き、履歴の記録は保存されません。一部のオブジェクト・フィールド・ページのレイアウトは、Hancom Hangul と違うことがあります。

大切な文書は、IeumOffice で保存したあと、一度 Hancom Hangul で開いて確かめてください。

AI の接続

ローカル LLM で使えますか？

使えます（0.12.6 から）。IeumOffice がモデルを直接動かすのではなく、自分の PC や社内ネットワークで動いている AI サーバー（Ollama など）に接続します。設定 → AI の ローカル AI でサーバーのアドレスを登録し、接続テストで会話ができるかを確かめます。

登録しただけでは使う AI は変わらず、自分で選んだサーバーだけを使います。サーバーのアドレスが PC の外のインターネット上のアドレスなら、文書がそちらに送られることを知らせます。インターネットがなくても、文書の編集と保存はできます。

AI

AI が「正しい呼び出しを送り直します」と言います

AI が文書を直すツールを間違った形式で送ると、アプリがそのリクエストを送り直すように案内します。少し待てば、もう一度答えることが多いです。

同じリクエストで何度も繰り返される場合は、リクエストを少し変えてみるか、どんなリクエストだったかをフィードバックを送るからお知らせください。画面と会話の記録を一緒に送っていただくと、原因を見つけやすくなります。

アップデート

アップデート情報をメールで受け取れますか？

メールや SMS でアップデート情報を送るサービスはありません。IeumOffice はメールアドレスを集めていません。

新しいバージョンは、アプリが 4 時間ごとに確認します。タブバーの ☰ メニュー → 更新を確認…（Mac ではヘルプ → 更新を確認…）ですぐに確認でき、新しいバージョンがあればアプリの中で知らせます。自動で確認しないようにするには、設定 → 情報 で アップデートを自動で確認 をオフにします。GitHub の Releases ページからもダウンロードできます。

GitHub で新しいリリースの通知を受け取りたい場合は、リポジトリの Watch → Custom → Releases を選んでください。

ここにない質問は、フィードバックを送るからお知らせください。どの画面でつまずいたか、何をしようとしていたかを書いていただくと、早く原因を見つけられます。
