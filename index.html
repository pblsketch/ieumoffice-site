한글부터 PDF까지, 한 창에서.

한글, 워드, 엑셀, 파워포인트, PDF, 마크다운, HTML, 마인드맵 파일을 탭으로 열어 고치고, 원래 형식 그대로 저장합니다. 한컴오피스나 MS 오피스가 없어도 되고, 무료입니다. 손이 많이 가는 일은 옆의 AI 창에 맡길 수도 있어요.

필요할 때만
AI에게 맡깁니다.

편집기 옆에 AI 창이 있습니다. 쓰지 않아도 오피스로 쓰는 데는 지장이 없어요. 표를 채우거나 문장을 다듬는 것처럼 손이 많이 가는 일을 맡기고 싶을 때 부탁하면, AI가 앱의 편집 도구로 열린 문서를 고칩니다.

화면 속 대화는 설명을 위한 예시입니다.

되돌릴 수 있습니다
AI가 무엇을 고쳤는지 보여 주고, 마음에 들지 않으면 되돌립니다.
자료로 새 문서를 만듭니다
고른 파일을 읽어 발표 자료, HTML 페이지, 마인드맵을 만듭니다.
내 문서에 묻습니다
홈에서 별표한 파일들을 골라 질문하면, 그 파일들을 읽고 답합니다.

AI를 써도 돈이 따로 들지 않습니다.

이음오피스는 PC에 설치해 로그인해 둔 Claude Code나 Codex를 실행해 답을 받아 옵니다. 요청은 내 구독의 사용 한도에서 차감되고, API 키를 따로 만들 필요가 없습니다.

연결 비용 언제 쓰이나
구독Claude나 ChatGPT 구독으로 로그인한 Claude Code, Codex 구독료 말고는 없습니다. 구독의 사용 한도에서 차감됩니다. 기본값
무료 AIOpenRouter, Google Gemini 무료 한도 안에서는 없습니다. 구독이 없을 때 설정에서 연결
쓴 만큼 내는 방식API 키, 종량제 계정 쓴 만큼 그 회사에 냅니다. 사용자가 직접 골랐을 때만

구독 한도가 다 차면 요청을 멈추고 이유와 다시 쓸 수 있는 시각을 알립니다. 요금이 나가는 연결로 저절로 바꾸지 않습니다.

서버도 계정도 없습니다.

이음오피스는 사용 통계를 보내지 않고, 문서는 내 PC에서 열고 저장합니다. PC 밖으로 나가는 것은 AI에게 부탁할 때 그 AI 회사로 보내는 내용입니다.

무엇이 어디로 가는지 전체 목록
  • Claude나 Codex의 로그인 정보를 읽거나 복사하거나 저장하지 않습니다.
  • 앱 안에 로그인 화면을 만들지 않습니다. 로그인은 그 회사의 화면에서 끝납니다.
  • 시키지 않은 AI 요청을 뒤에서 시작하지 않습니다.
  • Claude Code와 Codex는 앱이 끌 수 있는 도구를 모두 끈 채로 실행하고, 앱을 끄면 함께 끝냅니다.

코딩 에이전트도 같은 문서를.

앱에는 터미널 명령어 ieumoffice와 MCP 서버, 에이전트 스킬이 들어 있습니다. 설정 → 연동에서 등록하면 Claude Code, Codex, Cursor가 같은 파일을 읽고 고칩니다. 

PS> ieumoffice docs read 가을북페어_기획서.docx
PS> ieumoffice sheet read 북페어_예산표.xlsx
PS> ieumoffice open 북페어_발표.pptx

참고한 프로젝트

코드는 가져오지 않고 기능과 설계를 참고했습니다.

  • pdf-craft PDF를 마크다운·EPUB으로 바꾸는 기능을 만들 때 기능 구성을 비교했습니다.
  • claw-hwp 한글 문서용 AI 도구의 설계를 참고했습니다.
  • hwp-mcp 표 칸을 가리키는 방식 같은 한글 자동화 설계를 참고했습니다.
  • frontend-slides 슬라이드 템플릿 디자인을 이 프로젝트(MIT)를 바탕으로 다시 만들었습니다.
  • k-slide 템플릿의 한글 글꼴 조합을 참고했습니다.

설치는 세 단계.

  1. 설치 파일 받기

    아래 버튼으로 IeumOffice-Setup.exe를 받습니다. 64비트 Windows 10과 11용입니다.

  2. 경고가 뜨면 이렇게

    코드 서명이 없는 새 프로그램이라 Windows가 처음 보는 파일로 여깁니다. 크롬에서는 바로 받아집니다. Edge에서 "일반적으로 다운로드되지 않습니다"가 나오면 다운로드 목록에서 파일 옆의 … → 유지 → 자세히 표시 → 그래도 계속을 누릅니다. 설치 파일을 열었을 때 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.

    설치 파일은 이 사이트와 GitHub 릴리스 페이지에서만 받으세요.

  3. AI 연결하기

    첫 실행 안내에서 Claude Code나 Codex를 연결합니다. 구독이 없으면 무료 AI를 연결합니다. 나중에 설정에서 바꿀 수 있습니다.

Mac용 내려받기

Apple Silicon(M1 이후) · 베타

설치한 앱은 4시간마다 새 버전을 확인합니다. 화면 언어는 21개입니다.

Mac에서 처음 열 때 베타

Apple Silicon Mac(M1 이후)과 macOS 12 이상에서 씁니다. 사과 메뉴 → 이 Mac에 관하여에서 칩이 Apple M으로 시작하면 됩니다. Apple 개발자 서명이 없는 무료 베타라서, 처음 한 번만 직접 허용합니다.

  1. 받은 .dmg를 열고 IeumOffice를 응용 프로그램 폴더로 끌어다 놓습니다.
  2. 응용 프로그램 폴더에서 IeumOffice를 엽니다. 경고 창이 뜨면 완료를 누릅니다.
  3. 시스템 설정 → 개인정보 보호 및 보안을 열고, 아래쪽 "IeumOffice이(가) 차단되었습니다" 옆의 그래도 열기를 누른 뒤 Mac 암호를 넣습니다.
  4. 다시 뜨는 창에서 열기를 누릅니다. 다음부터는 바로 열립니다.

"손상되었기 때문에 열 수 없습니다"라고 나오면 휴지통으로 옮기지 말고, 터미널에서 아래 한 줄을 실행한 뒤 다시 엽니다.

xattr -dr com.apple.quarantine /Applications/IeumOffice.app

Mac판은 스스로 업데이트하지 않습니다. 새 버전이 나오면 앱이 알려 주니, 여기서 다시 받아 덮어 설치하세요. Claude Code나 Codex는 AI 연결 카드의 "공식 설치 안내"를 따라 설치합니다.
