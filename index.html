한글

한글 파일은
한글 파일 그대로.

공문이나 신청서처럼 한글 파일로 주고받는 문서를 열고 고칩니다. 다 고치면 원래 형식 그대로 저장하고, PDF로 만들거나 바로 인쇄할 수 있어요.

원래 형식으로 저장합니다
.hwp는 .hwp로, .hwpx는 .hwpx로 저장합니다. 파일을 처음 덮어쓸 때는 원본을 .bak으로 남겨 둡니다. 다른 이름으로 저장할 때는 두 형식 가운데 고를 수 있습니다.
한컴 한글에서 다시 열립니다
고쳐서 저장한 파일이 한컴 한글 2024에서 열리는지 실제 한글 문서 수백 개로 확인하며 만들었습니다.
새 문서와 PDF
빈 한글 문서를 홈에서 새로 만들고, 다 쓴 문서는 PDF로 만들거나 바로 인쇄합니다.
반복 작업은 AI 창에
표 칸 채우기, 행과 열 넣고 빼기, 누름틀 채우기, 각주와 차례 넣기 같은 일을 부탁할 수 있습니다.

한글 편집 화면은 오픈소스 rhwp로 만들었습니다.

AI

필요할 때만
AI에게 맡깁니다.

편집기 옆에 AI 창이 있습니다. 쓰지 않아도 오피스로 쓰는 데는 지장이 없어요. 표를 채우거나 문장을 다듬는 것처럼 손이 많이 가는 일을 맡기고 싶을 때 부탁하면, AI가 앱의 편집 도구로 열린 문서를 고칩니다. 자주 맡기는 일은 스킬로 저장해 두고 입력 칸에 /를 쳐서 불러 씁니다.

화면 속 대화는 설명을 위한 예시입니다.

되돌릴 수 있습니다
AI가 무엇을 고쳤는지 보여 주고, 마음에 들지 않으면 되돌립니다.
자료로 새 문서를 만듭니다
고른 파일을 읽어 발표 자료, HTML 페이지, 마인드맵을 만듭니다.
내 문서에 묻습니다
홈에서 별표한 파일들을 골라 질문하면, 그 파일들을 읽고 답합니다.

비용

AI를 써도 돈이 따로 들지 않습니다.

이음오피스는 이미 쓰고 있는 Claude나 ChatGPT 구독으로 답을 받아 옵니다. 요청은 내 구독의 사용 한도에서 차감되고, API 키를 따로 만들 필요가 없습니다.

구독료 말고는 없습니다. 구독의 사용 한도에서 차감됩니다.

무료 한도 안에서는 없습니다. 설정에서 연결합니다.

직접 골랐을 때만

쓴 만큼 내는 방식

API 키, 종량제 계정

쓴 만큼 그 회사에 냅니다.

구독 한도가 다 차면 요청을 멈추고 이유를 알립니다. 다시 쓸 수 있는 시각을 알 수 있으면 함께 알립니다. 요금이 나가는 연결로 저절로 바꾸지 않습니다.

개인정보

서버도 계정도 없습니다.

이음오피스는 사용 통계를 보내지 않고, 문서는 내 PC에서 열고 저장합니다. PC 밖으로 나가는 것은 AI에게 부탁할 때 그 AI 회사로 보내는 내용입니다.

개인정보 처리방침 전체 보기
  • Claude Code나 Codex의 로그인 정보를 읽거나 복사하거나 저장하지 않습니다. ChatGPT를 앱에서 바로 연결하면 OpenAI가 이 앱에 내준 로그인 하나만 이 PC에 두고, 연결을 끊으면 지웁니다.
  • 앱 안에 로그인 화면을 만들지 않습니다. 로그인은 그 회사의 화면에서 끝납니다.
  • 시키지 않은 AI 요청을 뒤에서 시작하지 않습니다.
  • Claude Code와 Codex는 앱이 끌 수 있는 도구를 모두 끈 채로 실행하고, 앱을 끄면 함께 끝냅니다. 에이전트 창만 예외로, 직접 고른 프로젝트 폴더에서 정해 둔 도구만 켭니다.

개발자

코딩 에이전트도 같은 문서를.

앱에는 터미널 명령어 ieumoffice와 MCP 서버, 에이전트 스킬이 들어 있습니다. 설정 → 연동에서 등록하면 Claude Code, Codex, Cursor가 같은 파일을 읽고 고칩니다. 

PS> ieumoffice docs read 가을북페어_기획서.docx
PS> ieumoffice sheet read 북페어_예산표.xlsx
PS> ieumoffice open 북페어_발표.pptx

참고한 프로젝트

코드는 가져오지 않고 기능과 설계를 참고했습니다.

  • pdf-craft PDF를 마크다운·EPUB으로 바꾸는 기능을 만들 때 기능 구성을 비교했습니다.
  • claw-hwp 한글 문서용 AI 도구의 설계를 참고했습니다.
  • hwp-mcp 표 칸을 가리키는 방식 같은 한글 자동화 설계를 참고했습니다.
  • frontend-slides 슬라이드 템플릿 디자인을 이 프로젝트(MIT)를 바탕으로 다시 만들었습니다.
  • k-slide 템플릿의 한글 글꼴 조합을 참고했습니다.
