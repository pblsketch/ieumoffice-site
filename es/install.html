  1. Al pulsar el botón Descargar, se abre el panel de descargas en la esquina superior derecha de Edge.
  2. Si ves «no se descarga normalmente», pon el puntero sobre el nombre del archivo y pulsa ··· (los tres puntos).
  3. En el menú, pulsa la primera opción, Conservar.
  4. Cuando aparezca el cuadro de confirmación, no pulses el botón azul Eliminar: pulsa Mostrar más, abajo a la izquierda.
  5. Pulsa la opción nueva, Conservar de todos modos.
  6. Ahora pulsa Abrir archivo y empieza la instalación.

Si al abrir el archivo sale una ventana azul, sigue con Aparece «Windows protegió su PC».

Windows 11

Aparece «Control inteligente de aplicaciones bloqueó…»

Es una ventana que sale a menudo en portátiles recién comprados o en PC con Windows recién instalado. IeumOffice se distribuye gratis y no tiene una firma con la que Windows pueda comprobar quién lo publica. Por eso Windows 11 lo bloquea no solo al instalarlo, sino también al ejecutarlo. Esta ventana no tiene botón Ejecutar, y tampoco hay forma de permitir solo este programa. Si desactivas Control inteligente de aplicaciones, se puede instalar y ejecutar. Pero si lo vuelves a activar, IeumOffice queda bloqueado, así que tiene que quedarse desactivado mientras uses IeumOffice.

Control inteligente de aplicaciones bloqueó una aplicación que puede no ser segura.

Esta aplicación se bloqueó para proteger tu dispositivo y tus datos. Microsoft revisa las aplicaciones para comprobar que son seguras.

Control inteligente de aplicaciones bloquea los programas desconocidos descargados de internet. Al desactivarlo pierdes esa protección, pero puedes usar IeumOffice. La Protección antivirus y contra amenazas (Defender) de Seguridad de Windows sigue activada, así que el análisis de virus continúa. Si más adelante lo vuelves a activar, IeumOffice dejará de ejecutarse.

Si después de desactivarlo aparece la ventana azul «Windows protegió su PC», pulsa en ella Más información → Ejecutar de todas formas. Lo explicamos en Aparece «Windows protegió su PC».

Aunque pulses Obtener aplicaciones en Microsoft Store, IeumOffice no aparece: no está publicado en la Store. En algunos PC aparece el aviso de que, una vez desactivado, no se puede volver atrás. Léelo antes de desactivarlo. Si después de cambiar la configuración sigue bloqueado, reinicia el PC. Si el PC te lo dio tu empresa o tu centro educativo, puede que no puedas cambiar esta configuración; avisa a quien administra el PC. Mac · Linux

Instalar en Mac y Linux

La primera vez que lo abres en Mac beta

Funciona con macOS 12 o posterior. Mira el chip en el menú Apple → Acerca de este Mac. Si empieza por Apple M, descarga el archivo para Apple Silicon; si dice Intel, el archivo para Intel. Es una beta gratuita sin firma de desarrollador de Apple, así que la primera vez tienes que permitirla tú.

  1. Abre el .dmg descargado y arrastra IeumOffice a la carpeta Aplicaciones.
  2. Abre IeumOffice desde la carpeta Aplicaciones. Si aparece una advertencia, pulsa OK.
  3. Abre Ajustes del Sistema → Privacidad y seguridad, pulsa Abrir igualmente junto a «Se ha bloqueado “IeumOffice”», más abajo, y escribe la contraseña del Mac.
  4. En la ventana que vuelve a aparecer, pulsa Abrir. A partir de entonces se abre directamente.

Si aparece que «está dañado y no se puede abrir», no lo muevas a la papelera: ejecuta esta línea en Terminal y vuelve a abrirlo.

xattr -dr com.apple.quarantine /Applications/IeumOffice.app

Desde la 0.12.11, si la aplicación está en la carpeta Aplicaciones, basta con pulsar Actualizar ahora → Reiniciar e instalar en la ventana de actualización para pasar a la versión nueva y volver a abrirla. Si usas la 0.12.10 o anterior, esta vez descarga aquí la 0.12.11 e instálala encima. Si abres la aplicación directamente desde la imagen de disco, la ventana de actualización abre la página de descarga. Si la aplicación no se actualiza sola, vuelve a descargarla aquí e instálala encima. Claude Code y Codex se instalan siguiendo la «Guía oficial de instalación» de la tarjeta de conexión de IA (conectar la IA en Mac).

Instalar en Linux beta

Hay tres archivos para Linux de 64 bits (x86_64). Descarga el que corresponda a tu distribución.

  • AppImage — Sin instalar nada: dale permiso de ejecución (chmod +x) y ábrelo. Se actualiza solo.
  • Paquete .deb — Familia Ubuntu y Debian: sudo apt install ./ieumoffice_*_amd64.deb
  • Paquete .rpm — Familia Fedora, RHEL y openSUSE: sudo dnf install ./ieumoffice-*.x86_64.rpm

.deb y .rpm se instalan en /opt/IeumOffice y enlazan el comando de terminal /usr/bin/ieumoffice. Cuando sale una versión nueva, la aplicación te avisa, y la AppImage se actualiza directamente desde la aplicación. Claude Code y Codex se instalan siguiendo la «Guía oficial de instalación» de la tarjeta de conexión de IA.

Si aun así no funciona, cuéntanos en Enviar comentarios en qué pantalla te quedaste. Si adjuntas una captura de esa pantalla, lo encontraremos antes.
