Windows 11

"Smart App Control blocked …" appears

This window often appears on a new laptop or on a PC with a fresh Windows installation. IeumOffice is distributed for free, so it has no signature that lets Windows confirm the publisher. Because of that, Windows 11 blocks it not only when you install it but also when you run it. This window has no Run button, and there is no way to allow just this one program. If you turn Smart App Control off, installing and running work. If you turn it back on, IeumOffice is blocked again, so you need to leave it off while you use IeumOffice.

Mac · Linux

Installing on Mac and Linux

Opening it the first time on a Mac Beta

It runs on macOS 12 or later. Check your chip under Apple menu → About This Mac. If it starts with Apple M, get the Apple Silicon file; if it says Intel, get the Intel file. It is a free beta without an Apple developer signature, so you allow it yourself the first time only.

  1. Open the downloaded .dmg and drag IeumOffice into the Applications folder.
  2. Open IeumOffice from the Applications folder. When a warning appears, click Done.
  3. Open System Settings → Privacy & Security, click Open Anyway next to "“IeumOffice” was blocked …" near the bottom, and enter your Mac password.
  4. In the window that appears again, click Open. From then on it opens directly.

If it says "… is damaged and can't be opened", don't move it to the Trash. Run the line below in Terminal, then open it again.

xattr -dr com.apple.quarantine /Applications/IeumOffice.app

From 0.12.11, an app in the Applications folder updates itself: in the update window, click Update Now → Restart & Install, and it changes to the new version and opens again. If you are on 0.12.10 or earlier, this one time get 0.12.11 here and install it over the old one. For an app opened straight from the disk image, the update window opens the download page. If the app doesn't update itself, download it here again and install it over the old one. Install Claude Code or Codex by following the "Official install guide" on the AI connection card (Connecting AI on a Mac).

Installing on Linux Beta

There are three files for 64-bit (x86_64) Linux. Pick the one that fits your distribution.

  • AppImage — No installation: give it permission to run (chmod +x) and open it. It updates itself.
  • .deb package — Ubuntu and Debian family: sudo apt install ./ieumoffice_*_amd64.deb
  • .rpm package — Fedora, RHEL and openSUSE family: sudo dnf install ./ieumoffice-*.x86_64.rpm

.deb and .rpm install to /opt/IeumOffice and link the terminal command /usr/bin/ieumoffice. When a new version comes out, the app tells you, and the AppImage updates right inside the app. Install Claude Code or Codex by following the "Official install guide" on the AI connection card.
