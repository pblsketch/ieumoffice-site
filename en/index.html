Hangul

Hangul files
stay Hangul files.

Open and edit the documents people exchange as Hangul (HWP) files, such as official letters and application forms. When you are done, save them in the original format, turn them into a PDF, or print them right away.

Saved in the original format
A .hwp file is saved as .hwp, and a .hwpx file as .hwpx. The first time a file is overwritten, the original is kept as a .bak file. With Save As you can pick either format, or make a PDF copy.
Opens again in Hancom Hangul
While building it, we checked with hundreds of real Hangul documents that edited and saved files open in Hancom Hangul 2024.
New documents and PDF
Start a blank Hangul document from Home, and turn a finished one into a PDF or print it. In the PDF editor, choose "PDF Converter" → "PDF to HWP" to bring a PDF in as a Hangul document and edit it.
Repetitive work goes to the AI panel
You can ask it to fill table cells, add or remove rows and columns, fill in form fields, and add footnotes or a table of contents.

The Hangul editing screen is built with the open-source rhwp.

AI

Hand work to AI
only when you need to.

An AI panel sits beside the editor. You can use the office without it. When there is tedious work you would rather hand off, such as filling a table or polishing sentences, ask, and the AI edits the open document with the app's own editing tools. Save the requests you make often as skills, and call them up by typing / in the input box.

The conversation on screen is an example for illustration.

You can undo it
The AI shows what it changed, and if you don't like it, you undo it.
New documents from your material
It reads the files you choose and makes slides, an HTML page, or a mind map.
Ask your own documents
Pick files you starred on Home and ask a question; it reads those files and answers.

Cost

Using AI costs nothing extra.

IeumOffice gets its answers through the Claude or ChatGPT subscription you already have. Requests count against your subscription's usage limit, and you don't need to create an API key.

Default

Subscription

Claude subscription (Claude Code), ChatGPT plan

Nothing beyond your subscription fee. Use counts against the subscription's limit.

Without a subscription

Free AI

OpenRouter, Google Gemini

Nothing within the free limit. You connect it in Settings.

Only if you choose it

Pay as you go

API key, pay-as-you-go account

You pay that company for what you use.

When the subscription limit is used up, requests stop and the app tells you why. If it can tell when you can use it again, it says that too. It never switches to a paid connection by itself.

Privacy

No server, no account.

IeumOffice sends no usage statistics, and your documents are opened and saved on your PC. What leaves your PC is what you send to an AI company when you ask its AI for something.

Read the full privacy policy
  • It does not read, copy or store the sign-in data of Claude Code or Codex. If you connect ChatGPT directly in the app, it keeps on this PC only the one sign-in OpenAI issued to this app, and deletes it when you disconnect.
  • It has no sign-in screen of its own. You sign in on that company's own page.
  • It never starts an AI request in the background that you did not ask for.
  • Claude Code and Codex run with every tool the app can turn off turned off, and they end when you close the app. The one exception is the agent window, which turns on a fixed set of tools only in a project folder you choose.

Developers

Coding agents work on the same documents.

The app includes the terminal command ieumoffice, an MCP server and an agent skill. Register them in Settings → Integrations, and Claude Code, Codex and Cursor can read and edit the same files. 

PS> ieumoffice docs read fall-book-fair-plan.docx
PS> ieumoffice sheet read book-fair-budget.xlsx
PS> ieumoffice open book-fair-talk.pptx
