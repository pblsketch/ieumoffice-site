Frequently asked questions

Supported systems

Can I use it on a phone, as a mobile version, on an iPad or on Android?

No. IeumOffice is a desktop program you install on a PC. There is no app for phones, mobile, iPhone, Android, iPad or tablets, and no version that opens in a web browser. It can't be installed as a tablet or mobile app.

Operating systemSupport
Windows 10 and 11 (64-bit)Full release
macOS (Apple Silicon, Intel)Beta
Linux x64 (AppImage, deb, rpm)Beta
iPad, iPhone, AndroidNot supported

Can I use it on a Mac (beta)?

Yes. For Mac, both Apple Silicon and Intel are released as beta: Apple Silicon for M1 and later, and Intel from 0.12.4. You choose the installer on the download page.

Since when does it work on Intel Macs?

Intel Macs have been supported as beta since 0.12.4, alongside Apple Silicon. You can choose the Intel Mac installer on the download page. Because Mac and Linux are in beta, some parts have not been checked by the developer directly and are confirmed through user reports.

Does it work on Windows 7 or 32-bit Windows?

No. Only 64-bit Windows 10 and 11 are supported. It can't be installed on 32-bit Windows or on Windows 7 or earlier.

Cost

Is it really free? What does it cost?

The program is free. Editing and saving documents have no paid limits, and you need no account or subscription. IeumOffice charges nothing.

The AI features run on the Claude or ChatGPT subscription you already have, or on an API key you enter yourself. The subscription fee goes to that company, and you pay nothing extra to IeumOffice. With an API key (OpenRouter, Gemini), that company may charge you for what you use, and some keys come with a free limit.

The app never switches you to a paid API key or a pay-as-you-go connection by itself. When a limit is used up, it stops the request and tells you why.

Install

Is there a portable version that runs without installing?

No. There is not yet a portable (zip) version that runs without installing, or a version to carry on a USB drive.

On Windows, install it once with the installer (.exe), then start it from the Start menu or the desktop. On a Mac, open the .dmg and move it to the Applications folder. On Linux, run the AppImage or install the .deb or .rpm.

If installing gets stuck, open Install help and pick the screen you see.

Install

How do I uninstall the program?

On Windows, find IeumOffice in Settings → Apps → Installed apps and click Uninstall. On a Mac, move IeumOffice from Finder → Applications to the Trash. On Linux, depending on how you installed it, use sudo apt remove ieumoffice or sudo dnf remove ieumoffice, or delete the AppImage file.

If uninstalling stops partway or you can't install again, install the same version once more and then try uninstalling again. If that doesn't work, tell us through Send feedback which screen it stopped on.

Settings and the recent documents list may stay in the user data folder (Windows %APPDATA%\IeumOffice, Mac ~/Library/Application Support/IeumOffice, Linux ~/.config/IeumOffice). To remove everything, delete this folder yourself after uninstalling.

Install

At first launch it freezes on "Not responding" or a gray screen

This happened on PCs where Windows Security's Controlled folder access (ransomware protection) is on. That feature stops new folders from being created in the Documents folder, so up to 0.12.7 the app could freeze on first launch on such PCs. Updating to 0.12.8 or installing it fresh fixes this.

From 0.12.8, if the app can't write to the Documents folder, it saves new files in an IeumOffice folder under your user folder and shows the notice "Can't save to the Documents folder" once. To save to the Documents folder as before, add IeumOffice under Allow an app through Controlled folder access in Windows Security and restart the app. You can also pick another folder in Settings → General → Save Location.

Hangul

A Hangul file won't save, and it says it was "not saved"

When saving, IeumOffice first writes a new file, then reads that file back to check that it matches the screen. If what it reads back differs from the screen, it stops without overwriting the original. So your original file is still there. It does not mean the file is broken; the app stopped so as not to ruin the original with a result that differs from the screen. This check runs only when saving as .hwp. .hwpx is a different format and is not checked this way.

  1. In Save As, change the file type to HWPX and save to a new file. After saving, open it in Hancom Hangul to check it.
  2. If you still need .hwp, choose HWP in Save As and try saving to a new file. It may hit the same check again.
  3. If that fails, keep what is on screen with Export as PDF.
  4. If nothing works, send us the document through Send feedback. A copy with personal information removed or changed is fine.

If the app closed suddenly, it offers a recovered copy the next time it starts. Recovered copies are kept in hwp-autosave in the user data folder.

Markdown

Clicking a link in Markdown doesn't open it

In the Markdown editor, a plain click on a link puts the cursor in it so you can edit the link text. To open a link, hold Ctrl and click (on a Mac, hold ⌘ and click). In read-only views such as the presentation screen (F5), a plain click opens it.

Only web addresses (http, https) and email addresses (mailto) open, in your default browser. Relative paths in the document, file:// addresses, and links in the source view (Ctrl+E) don't open yet.

The pointer turns into a hand over a link, yet a single click doesn't open it while you edit. That is so you can edit the link text right where it is.

PDF

Can I paste a screenshot into a PDF, or copy a page?

Not yet. Pasting a screenshot from the clipboard with Ctrl+V in the PDF editor, and copying a whole page to the clipboard at once, have not been added yet.

For now there are two ways around it.

  • Save the screenshot as an image file and put it into the PDF with Insert image / stamp.
  • Save pages as PNG files with PDF tools → Export images.

Pasting screenshots and copying pages have already been requested through Send feedback. If you need them too, tell us through Send feedback.

Excel

How compatible is it with Excel files?

Everyday .xlsx work is covered: cell editing, formulas, formatting, tables, charts (9 types), pivot tables, conditional formatting, sorting and filtering, data validation, and sheet and workbook protection. .csv and .tsv files also open as tables and are saved in their original format.

That said, it does not support every Excel feature in exactly the same way.

  • VBA macros are not run. When you open and save an .xlsm file, the part that stores the macros is left as it is, not deleted.
  • External data connections and some advanced pivot tables, charts and OLE objects may come out differently from Excel.
  • On saving, it reads the result back, and if it can't be read, the original is not overwritten. For important documents, open them once in Excel after saving to check.

If a feature doesn't carry over, tell us through Send feedback and attach the file. A copy with personal information removed or changed is fine.

Excel

How do I make rows the same height in Excel?

To give cells (rows) the same height, select several row headers (1, 2, 3…), choose Format → Row Height… on the ribbon, and enter one value. The selected rows then have the same height. To fit them to their content, use Format → AutoFit Row Height.

Column width works the same way, under Format → Column Width…. You can also drag the edge of a header to resize, or double-click the edge to fit automatically.

Connecting AI

Can I use it with a ChatGPT plan? Do I need the Codex program?

Yes, and from 0.12.8 you don't need the Codex program. In the connection guide, choose I use ChatGPT and click Continue with ChatGPT, and a ChatGPT sign-in page opens in your browser. Sign in and allow this app to use your plan, and it is connected. The ChatGPT card in Settings → AI does the same. To see it on screen, open AI connection help.

If you already use the Codex program on this PC, you can connect through Codex. Agent mode and the terminal command still need the Claude Code or Codex program, as before.

When AI to use is set to Automatic, the app picks among what is connected in this order: Claude, ChatGPT, Codex. It never picks a paid API key or a pay-as-you-go sign-in automatically.

AI

Do I have to give the AI the same background for every document?

From 0.12.9, group them in a project. Under Project below the AI panel's input box, create a New project or use Add folder to pick a folder you already work in. The instructions you write on the Projects screen on Home, and the memory the AI builds up while chatting, go along with every request in that project. The AI finds and reads files in the folder, and chats in the same project carry on in other editors.

Instructions, memory and chats are kept in the .ieumoffice folder inside that folder. Files you don't want the AI to see can be left out under Files on the project screen. If you don't pick a project, each document has its own chat, as before.

Files

Can I open files from Google Drive?

Yes, from 0.12.9. Connect Google Drive in Settings → Integrations, then click Choose from Google Drive on Home, and Google's file picker opens. The file you choose opens in a tab, and saving uploads it to Drive again. You can also choose Drive files when attaching in the AI panel.

The app opens only files you chose in the picker and files it created itself; it doesn't see the rest of your Drive. Before passing a Drive file to the AI, it asks you once to check that model training is turned off in the AI account you use. Drive files are never passed to a free AI connection.

Connecting AI

Can I connect with a paid Gemini plan?

A Gemini Advanced (Google One AI Premium) subscription can't be used directly for AI in IeumOffice. The Gemini you connect under Use for free is an API key made in Google AI Studio.

If you enter a paid Gemini API key, Google may charge you for what you use, and some keys come with a free limit. The app never switches you to a paid API key by itself.

If you have a Gemini Advanced subscription, for now you need to connect a Claude or ChatGPT subscription, or make an API key in Google AI Studio and connect that.

License

Can I use it for work at a company or organization?

Yes. IeumOffice is free, open-source software released under the Apache License 2.0. Companies, schools and public institutions can use it for work without any separate subscription, and editing and saving documents have no paid limits.

The AI features run on each user's Claude or ChatGPT subscription or on an API key they enter. If you manage them with company accounts, check that provider's terms. The app sends no usage statistics, and documents stay on the PC.

The full license text is in LICENSE on GitHub.

Hangul

How is it different from Hancom Hangul?

The IeumOffice Hangul editor opens and saves .hwp and .hwpx, and handles basic editing such as text, tables, styles and shortcuts. Many shortcuts match those of Hancom Hangul 2024, and you can also have AI edit the document or export it to PDF.

It does not reproduce every feature of Hancom Office. Documents with tracked changes open with their current content, and the change history is not saved. Some objects, fields and page layouts may differ from Hancom Hangul.

For important documents, save them in IeumOffice and then open them once in Hancom Hangul to check.

Connecting AI

Can I use it with a local LLM?

Yes (from 0.12.6). IeumOffice doesn't run models itself; it connects to an AI server (such as Ollama) running on your PC or your organization's network. Register the server address under Local AI in Settings → AI, and use Test connection to check that chatting works.

Registering a server doesn't change which AI is used; only a server you choose yourself is used. If the server address is on the internet outside your PC, the app tells you that documents will go there. Editing and saving documents work without the internet.

AI

The AI says it is "sending a correct call again"

When the AI sends a call to a document-editing tool in the wrong format, the app asks it to send the request again. If you wait a moment, it often answers again.

If it keeps repeating on the same request, try wording the request a little differently, or tell us through Send feedback what the request was. A screenshot and the chat history help us find it.

Updates

Can I get update news by email?

There is no service that sends update news by email or text message. IeumOffice does not collect email addresses.

The app checks for a new version every 4 hours. You can check right away with ☰ menu → Check for Updates… in the tab bar (on a Mac, Help → Check for Updates…), and if there is a new version, the app tells you. To stop automatic checks, turn off Check for updates automatically in Settings → About. You can also download it from the GitHub Releases page.

To get notified of new releases on GitHub, choose Watch → Custom → Releases on the repository.

For questions not covered here, tell us through Send feedback. If you write which screen you got stuck on and what you were trying to do, we can find it faster.
